수업 소개

AI 에이전트 웹 수업이란?

코딩 없이 AI 에이전트에게 지시만 해서 실제 브라우저에서 동작하는 웹 페이지를 만들고, 나아가 데이터·회원·결제까지 갖춘 진짜 사이트로 배포하는 16주 코스입니다. 원하는 것을 말하면 AI 에이전트가 코드를 생성하고, 눈앞에서 결과물이 나옵니다.

코딩 지식 불필요

HTML·CSS·JavaScript를 직접 쓸 줄 몰라도 됩니다. 원하는 페이지를 말로 설명하면 AI 에이전트가 코드를 생성합니다. 지시어(프롬프트)만으로 결과물을 만듭니다.

회차당 1개념

매 회차마다 한 가지 개념과 결과물에 집중합니다. 한 번에 몰아치지 않고, 학습 흐름이 끊기지 않게 단계별로 쌓아 올라갑니다.

기초 + 심화 16주

기초 8주는 보이는 웹을, 심화 8주는 데이터·회원·AI 기능·결제가 동작하는 진짜 사이트를 만듭니다. 학습 단계가 명확히 분리되어 있습니다.

16주 로드맵

기초 8주 + 심화 8주, 한눈에

기초 트랙에서 "보이는 결과물"을 만드는 감각을 익히고, 심화 트랙에서 "동작하는 서비스"로 확장합니다. 두 트랙이 하나의 흐름으로 연결됩니다.

JS 인터랙션 기초 — 3대 트리거

정적인 사진 같던 페이지에 click·scroll·mousemove 3대 트리거를 붙여 반응하는 페이지로 진화시킵니다.

수업 목표

JS가 페이지에 "행동"을 부여한다는 것을 이해하고, click·scroll·mousemove 3대 트리거의 차이를 파악합니다. 클릭 토글, 스크롤 등장(IntersectionObserver), 마우스 따라가기를 각각 실습으로 완성합니다.

  • 3대 트리거 (click · scroll · mousemove) 비교
  • IntersectionObserver — 스크롤 등장의 원리
  • 실습 — 클릭 토글(연락하기 버튼) / 스크롤 등장 / 마우스 따라가기
