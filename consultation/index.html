수업 소개

AI 에이전트 웹 수업이란?

코딩 없이 AI 에이전트에게 지시만 해서 실제 브라우저에서 동작하는 웹 페이지를 만드는 16주 코스입니다. 원하는 것을 말하면 AI 에이전트가 코드를 생성하고, 눈앞에서 완성된 결과물이 나옵니다.

코딩 지식 불필요

HTML·CSS·JavaScript를 직접 쓸 줄 몰라도 됩니다. 원하는 페이지를 말로 설명하면 AI 에이전트가 코드를 생성합니다. 지시어(프롬프트)만으로 결과물을 만듭니다.

회차당 1개념

매 회차마다 한 가지 개념과 결과물에 집중합니다. 한 번에 몰아치지 않고, 학습 흐름이 끊기지 않게 단계별로 쌓아 올라갑니다.

기초 + 심화 16주

기초 8주는 보이는 웹을 탄탄히 만들고, 심화 8주는 더 풍부한 기능을 더해 한 단계 확장합니다. 학습 단계가 명확히 분리되어 있습니다.

16주 로드맵

기초 8주 + 심화 8주, 한눈에

기초 트랙에서 "보이는 결과물"을 만드는 감각을 익히고, 심화 트랙에서 "동작하는 서비스"로 확장합니다. 두 트랙이 하나의 흐름으로 연결됩니다.

기초 8주차 — 회차별 상세

WEEK 01–03

웹의 기초 — 첫 체험부터 HTML·CSS까지

Claude Code 첫 체험으로 시작해, 페이지의 뼈대(HTML)를 세우고 색·폰트·여백(CSS)으로 디자인을 입히는 3주간의 기초 과정입니다.

수업 목표

"AI 에이전트에게 지시만 하면 코드가 생긴다"는 첫 경험으로 시작합니다. 웹의 3갈래(HTML=뼈대 · CSS=꾸미기 · JS=움직임)와 16주 전체 지도를 그린 뒤, HTML로 페이지 뼈대를 세우고 CSS로 색·폰트·여백을 입혀 "같은 뼈대, 다른 옷"을 직접 경험합니다.

3주간 배우는 내용
  • 1주 · Claude Code 첫 체험 + 16주 전체 로드맵
  • 웹의 3갈래 — HTML(뼈대) · CSS(꾸미기) · JS(움직임)
  • 2주 · HTML로 페이지 뼈대 세우기 (의미별 구역 나누기)
  • 3주 · CSS로 색·폰트·여백 입히기
  • 클래스·컴포넌트로 디자인 재사용 (Before/After 비교)
  • "AI를 부리는 사람"이라는 관점 — 외주 비유
WEEK 04

JS 인터랙션 기초 — 3대 트리거

정적인 사진 같던 페이지에 클릭·스크롤·마우스 3대 반응을 붙여 반응하는 페이지로 진화시킵니다.

수업 목표

JS가 페이지에 "행동"을 부여한다는 것을 이해하고, 클릭·스크롤·마우스 3대 반응의 차이를 파악합니다. 클릭 토글, 스크롤하면 나타나는 효과, 마우스 따라가기를 각각 실습으로 완성합니다.

배우는 내용
  • JS의 역할 — 사진에서 엘리베이터로
  • JavaScript란 — 한 줄로 시작하는 행동 언어
  • 3대 트리거 (클릭 · 스크롤 · 마우스) 비교
  • 스크롤하면 스르륵 나타나는 효과의 원리
  • 실습 — 클릭 토글(연락하기 버튼) / 스크롤 등장 / 마우스 따라가기
수업 결과물 예시
마우스 따라가기 · 마우스 따라다니는 커서
스크롤 페이드인 · 스크롤 시 섹션 등장
WEEK 05

GSAP — 영화 같은 스크롤

수업 목표

라이브러리가 무엇인지, CDN으로 어떻게 불러오는지 이해합니다. GSAP ScrollTrigger로 수평 스크롤·텍스트 컬러 reveal·패럴랙스 같은 "영화 같은 스크롤" 효과를 지시 한 줄로 완성하는 경험을 합니다.

배우는 내용

WEEK 09

API 연동 — 데이터가 살아 움직이는 페이지

외부에서 데이터를 가져오는 fetch와 JSON, 그리고 API 키 개념을 익히고 실시간 데이터를 페이지에 띄웁니다.

수업 목표

"내가 쓴 데이터"가 아니라 "외부 데이터"를 받아와 페이지에 띄우는 첫 경험을 합니다. API와 fetch의 개념을 자판기 비유로 잡고, API 키가 왜 필요한지 이해하며 키 없는 무료 API부터 기상청 API허브까지 연결하고, 한국 공개 API 목록에서 골라 자유 제작합니다.

배우는 내용
  • API란 — 자판기 비유
  • fetch와 JSON — 한 줄 명령 + 데이터 형식
  • API 키 첫 등장 — 왜 필요한가
  • 실습 — 키 없는 무료 데이터 (고양이 이미지)
  • 실습 — 기상청 API허브로 날씨 카드
  • 실습 — 한국 공개 API 목록에서 골라 자유 제작

"데이터 설계도"라는 개념을 잡고, 내 컴퓨터에 작은 서버(Flask)를 켜 CSV 파일에 데이터가 쌓이는 방명록과 쇼핑몰을 만듭니다.

수업 목표

데이터를 그냥 늘어놓는 게 아니라 "구조화"한다는 개념을 잡습니다. 데이터에도 설계도가 필요하며, 내 컴퓨터에 작은 서버(Flask)를 켜고 CSV 파일이 곧 데이터베이스가 되는 흐름을 직접 봅니다. 폼 입력이 CSV에 쌓이는 방명록과 상품목록 쇼핑몰을 완성합니다.

배우는 내용
  • 데이터를 '구조화'한다는 것 · 설계도
  • 서버란? 내 컴퓨터에서 켜는 작은 프로그램
  • CSV가 곧 우리의 데이터베이스
  • 실습 — 작은 서버(Flask)로 입력을 CSV에 저장
  • 실습 — 목록 표시 · 삭제 동기화
  • 실습 — 상품목록 CSV로 로컬 쇼핑몰

클라우드 DB — Supabase로 도약

내 컴퓨터를 넘어 클라우드 DB로. Claude Code에 Supabase를 연결(MCP)해 프롬프트만으로 프로젝트·테이블을 만들고, 지난주 쇼핑몰을 클라우드로 전환합니다.

수업 목표

10주 데이터는 내 컴퓨터에만 남아있었습니다. 이번 주는 "어디서나 같은 데이터"를 보는 클라우드 DB로 도약합니다. Claude Code 플러그인(MCP)으로 Supabase를 연결해 프롬프트만으로 프로젝트·테이블을 만들고, CRUD 4종 개념을 잡은 뒤 지난주 로컬 CSV 쇼핑몰을 클라우드로 옮깁니다. 배포 후 무료 DB가 잠들지 않게 하는 법까지.

배우는 내용
  • Claude Code + Supabase 연결 (MCP)
  • 테이블 + 컬럼 = 데이터의 엑셀 시트
  • CRUD 4종 (Create · Read · Update · Delete)
  • 실습 — 프롬프트로 프로젝트·테이블 생성
  • 실습 — 로컬 쇼핑몰을 클라우드로 전환
  • 실습 — 배포 + 잠듦 방지 · 보안은 규칙 한 줄
