한 번 돌릴 때마다 30~40분 걸리던 claude -p 생성을, 품질을 유지한 채 ~10분으로 줄인 파이프라인입니다. 원인은 코딩 분량이 아니라 모델의 과잉 사고 + 쉘 자가검증 루프였습니다. 아래 4개는 서로 다른 도메인에 무작위 시드를 배정해 이 파이프라인으로 생성한 결과(전부 자동 교정까지 거쳐 perfcheck 0 FAIL)입니다.

파이프라인 — 비싼 모델 자가검증을 분해

  1. 생성: --effort low(사고 1패스) + --disallowedTools Bash(쉘 자가검증 루프 차단). 약 10분.
  2. 검사: perfcheck.sh가 성능(THE LAW/TRAP)·마감(em-dash·이모지·끊긴 링크)을 정적으로 적발. 밀리초·공짜.
  3. 교정: FAIL이면 같은 세션을 --resume해 적발 항목만 ~10초 수정. 재생성 안 함.
