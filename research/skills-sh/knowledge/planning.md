# 지식 노트 — 기획/PM/UX리서치/브레인스토밍 (sweep 1, 2026-06-03)

SPARK의 PHASE -1~4(Purpose Archaeology, Audit, Domain Thinking, Self-Audit)와 LIGHTBULB 강화 관점.

## 조사 스킬 요약

### brainstorming (obra/superpowers) — https://www.skills.sh/obra/superpowers/brainstorming
- 코드 전 9단계 게이트: 컨텍스트 탐색→시각 동반물→**1질문씩**→대안2~3+트레이드오프→섹션별 승인→설계문서 저장→자기검토→사용자 승인→writing-plans로만 전환.
- 반영: PHASE -1에 "1질문씩" 대화형, PHASE 4에 "placeholder/모순/모호성 스캔", 단방향 게이트 모델.

### writing-plans (obra/superpowers) — github.com/obra/superpowers/.../writing-plans
- 승인 설계를 2~5분 태스크로 분해. **No-go 패턴**: TBD/TODO/placeholder/모호어/미정의 참조 → 게이트 불가.
- 반영: Self-Audit를 "No-go 패턴 스캔"으로 명문화.

### create-prd (phuryn/pm-skills) — github.com/phuryn/pm-skills
- 8섹션 PRD(Objective=SMART OKR, Value Prop=gains/pain avoidance/경쟁우위). 가정은 검증 플래그, 날짜는 상대 시점.
- 반영: Purpose Archaeology 4질문, Value Prop 3축을 차별화 발굴 프레임으로, 가정 플래그.

### Product-Manager-Skills (deanpeters) — github.com/deanpeters/Product-Manager-Skills
- Interactive Advisor(3~5 적응형 질문 1개씩→번호형 추천, 이전답 재진술). diagnose→frame→validate→execute.
- 반영: Audit 슬로건 "행동 전 진단/비명시 전략 표면화", 질문→번호추천 UX.

### discovery-interview-prep (deanpeters) — github.com/deanpeters/.../discovery-interview-prep
- Mom Test **안티패턴 표**(유도/가설/예아니오 ❌→⭕ 교정), 질문별 rationale+"피할 버전", 약한 증거 **Caveat injection**.
- 반영(고가치): PHASE -1 질문 품질 구조화, Self-Audit 경고 자동 부착.

### pm-skills Triple Diamond (product-on-purpose) — github.com/product-on-purpose/pm-skills
- 6단계(Discover→Define→Develop→Deliver→Measure→Iterate). **Readiness Gate**(다음 단계 적기인가 메타 게이트). **CI 강제 계약**(죽은 참조/일관성/누락 머신 검증).
- 반영(고가치): PHASE 전이마다 readiness gate, Self-Audit를 CI 계약식 기계 검증.

### claude-skills-library (maryeliz-design) — github.com/maryeliz-design/claude-skills-library
- ux-designer→ux-copywriter→ui-designer 핸드오프("내가 안 하는 것" 명시). **spec-qa: 이진 READY/NOT READY + 블로커 + 신뢰도 점수**. user-context(페르소나/숙련도→톤·밀도).
- 반영(고가치): Self-Audit를 이진 판정+블로커+confidence로, PHASE 0에 페르소나 캡처, PHASE별 스코프 경계.

### UXR Bundle / Research Synthesizer 등 (greatquestion 큐레이션)
- 다중 전사→테마+**모순 플래그**+의외 발견+빈도 매핑. Affinity outlier 식별. JTBD 4 forces(push/pull/anxiety/habit).
- 반영: Domain Thinking 산출을 "긴장점 표면화"로, JTBD를 LIGHTBULB 변화동기 프레임으로.

### UX Copywriting/Microcopy 원칙
- 명확성→보이스 순서, 1문구1아이디어, 1개념1용어, 에러는 무슨일/왜/뭐하라(지지적 톤).
- 반영: 카피 산출 규칙 + 에러/엠프티 문구 지지적 톤.

## 이 분야 신규 Top 5
1. **이진 품질 게이트 + 신뢰도 점수**(spec-qa) — Self-Audit를 READY/NOT READY+블로커+confidence로.
2. **No-go 패턴 스캔**(writing-plans) — TBD/모호어/미정의 참조 = 게이트 불가.
3. **Mom Test 안티패턴 표 + Caveat injection**(discovery-interview-prep) — 목적발굴 질문 품질 구조화.
4. **Readiness Gate + CI 강제 계약**(Triple Diamond) — 메타 게이트 + 기계 검증.
5. **단방향 게이트 체인 + 1질문씩 + 섹션별 승인**(brainstorming) — PHASE 골격·LIGHTBULB 연계 원형.
