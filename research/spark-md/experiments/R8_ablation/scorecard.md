# Round 8 — LIGHTBULB Ablation (v4 vs v4-noLB)

2주제(mokza 에디토리얼 / plain 미니멀) × {v4(LB 있음), v4-noLB}. stream-json 캡처.

## 통제 검증
- v4: lightbulb curl 실행 + id 추출(mokza lb-162/187/213, plain lb-098/138/164).
- v4-noLB: curl 0, id none. → 대조군 정상(영감 주입 차단 확인).

## 결과 (시각 비교)
- **mokza: v4(LB) ≈ noLB 거의 동일** — 같은 "MOK"+골드"ZA" 세리프, 같은 다크 톤, 같은 nav/구조. 유일 차이: v4에 떠다니는 입자·온기 그라데이션(표면 VISUAL_SPARK).
- **plain: 양쪽 다 라이트 미니멀** — 거대 "PLAIN" + 사이드 텍스트. 차이 미미.

## 결론 — LIGHTBULB 효과 = 낮음(표면 장식)
- 결과물의 레이아웃·타이포·구조·톤은 **domain + 다이얼 + 디자이너 규칙**이 결정. LIGHTBULB는 표면 텍스처(입자/온기)만 추가.
- 즉 현재 LIGHTBULB ≈ **선택적 폴리시**, 창의성 동력 아님. (CEO 의심 입증)
- 함의: LB가 결과를 바꾸게 하려면 **표면이 아니라 구조/컨셉을 주도**하게 해야(=v5-B 방향). 아니면 LB는 "있으면 좋은 양념"으로 격하.
