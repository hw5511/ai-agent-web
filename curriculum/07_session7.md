### 슬라이드별 topics

- **02 5종 카탈로그**: tsParticles(파티클 배경) / Typed.js(타이핑) / Three.js(3D) / VANTA(WebGL 배경) / Canvas 2D(직접 그리기)
- **03 파티클**: 점 수·색·반응 거리 자연어로 지시 / 다크 배경 + 흰 점 조합
- **04 타이핑**: 문자열 배열 → 타이핑 → 삭제 반복 / 포트폴리오 직함에 활용
- **05 3D**: Scene/Camera/Renderer 개념 / BoxGeometry + 회전
- **06 Canvas**: beginPath/arc/fillRect / requestAnimationFrame 루프 / 별자리 파티클
- **07 통합**: 5종 중 페이지 분위기에 맞게 1~2개 선택
- **08 4요소**: 대상 + 스타일 + 수치 + 범위 = 결과물 통제력
