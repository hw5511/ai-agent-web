# Session 9 — API 연동 (fetch + 외부 데이터)

## 회차 개요

- **시간**: 2시간
- **트랙**: 심화 / Part 2 (시작)
- **1개념**: **API 연동 (fetch)**
- **목표**: fetch + JSON으로 외부 API에서 데이터를 가져와 페이지에 뿌린다. API 키 개념을 처음 만난다.
- **누적 위치**: **Part 2 시작**. 정적 페이지 → 동적 페이지 전환점.
- **회차 끝 학생 상태**: 외부 데이터(날씨·환율·이미지 등) 받아서 보여주는 페이지

### 슬라이드별 topics

- **02 API**: 우리 서버 없이 외부 데이터 받는 법 / 자판기 비유 (요청 → 응답)
- **03 fetch + JSON**: fetch URL → response → json() / 키-값 구조
- **04 무료 API**: api.thecatapi.com (이미지) / api.quotable.io (명언) — 키 없이 즉시
- **05 API 키**: 발급은 보통 회원가입 + 키 페이지 / 공개 API 키는 노출 OK / "진짜 키"는 14주차에서 보호 학습
- **06 날씨**: OpenWeatherMap 무료 키 / 도시 입력 → 날씨 표시
- **07 검색·필터**: 받은 데이터 배열에서 필터링 / 입력란과 연결

### 실습 프롬프트
