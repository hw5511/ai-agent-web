### 슬라이드별 topics

- **02 JS 역할**: HTML+CSS = 고정 화면(사진) / JS = 행동(엘리베이터)
- **03 3대 트리거**: click(버튼·메뉴) / scroll(섹션 등장·패럴랙스) / mousemove(자기·빛 추적)
- **04 클릭**: addEventListener('click') / class 토글 / 메시지·색·표시 변경
- **05 스크롤 등장**: IntersectionObserver = "이 요소가 화면에 들어왔는지" 감지
- **06 스크롤 실습**: opacity 0 → 1 + translateY로 아래에서 위로
- **07 마우스 추적**: e.clientX·e.clientY / transform: translate

### 실습 프롬프트

| 실습 | 프롬프트 |

| 04 클릭 | 연락하기 버튼을 클릭하면 "감사합니다! 곧 연락드리겠습니다." 메시지가 나타나는 JS를 추가해줘. |
| 06 스크롤 등장 | 각 섹션이 스크롤로 화면에 보일 때 아래에서 위로 페이드인 되도록 IntersectionObserver로 구현해줘. |
| 07 마우스 따라가기 | 히어로 섹션 위에 마우스 따라다니는 동그란 커서 효과를 추가해줘. |
