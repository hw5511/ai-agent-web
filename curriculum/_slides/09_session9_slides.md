### 슬라이드 3 — 개념 ①: API란 무엇인가 (자판기 비유)
- **유형**: 개념
- **goal**: API = "외부 데이터를 주는 서비스의 창구"라는 직관을 자판기 비유로 잡는다.
- **핵심 토픽**:
  - 우리 페이지는 자판기 앞 손님
  - 외부 데이터를 주는 서비스 = 자판기
  - 요청(주문) → 응답(상품)이 한 번의 거래
  - 우리가 직접 데이터를 만들 필요 X — 이미 만들어둔 서비스를 빌려 씀
  - 예: 날씨, 환율, 지도, 이미지, 번역 등 거의 모든 분야에 존재
- **시각 요소**:
  - 자판기 일러스트 (왼쪽 손님 = 내 페이지 / 오른쪽 자판기 = 외부 서비스)
  - "동전 넣기 → 음료 받기" 화살표를 "요청 → 응답"으로 라벨링
  - 하단 가로 띠: 분야별 데이터 아이콘 (날씨/환율/뉴스/이미지/지도)
- **강사 노트**: "직접 날씨 정보 만들기는 불가능하죠. 기상청이 만든 걸 빌려 쓰는 거예요. 그 빌려 쓰는 통로가 오늘 배우는 거예요."

### 슬라이드 4 — 개념 ②: fetch와 JSON (한 줄 명령 + 데이터 형식)
- **유형**: 개념
- **goal**: fetch는 "주소 URL로 데이터 요청하는 명령", JSON은 "받아오는 데이터의 모양"임을 안다.
- **핵심 토픽**:
  - **fetch**: 브라우저에 기본 탑재된 명령 — 주소 URL에 데이터를 달라고 부탁
  - **JSON**: 키-값 쌍으로 된 데이터 형식 — 사람도 읽을 수 있는 메모지
  - 흐름: 주소 URL → fetch → 응답 → JSON으로 풀기 → 화면에 표시
  - 키-값 예: `{ "city": "Seoul", "temp": 22 }` (학생에게는 "이름표 + 값")
  - 우리는 외워서 쓰지 않음 — Claude Code가 다 작성, 우리는 흐름만 이해
- **시각 요소**:
  - 4단계 흐름 다이어그램: [주소 URL] → [fetch] → [응답] → [JSON 풀기] → [화면 표시]
  - 우측 코드박스 (보여주기용, 외우는 거 X):
    ```js
    const res = await fetch("주소 URL");
    const data = await res.json();
    ```
  - JSON 샘플 박스: `{ "city": "Seoul", "temp": 22 }`
- **강사 노트**: "두 단어만 기억하세요 — fetch, JSON. 코드는 클로드가 짭니다. 우리는 '아, 이거 fetch로 받아오는 거구나' 하고 알아보기만 하면 돼요."

### 슬라이드 5 — 개념 ③: API 키 첫 등장
- **유형**: 개념
- **goal**: API 키가 "신분증" 역할이며, 발급·사용·노출 범위에 대한 기본 감각을 잡는다.
- **핵심 토픽**:
  - 무료 서비스 중 일부는 "누가 쓰는지" 알기 위해 키를 요구
  - 발급 방법: 보통 회원가입 → 키 페이지에서 복사
  - 공개용 키(무료 등급)는 코드에 적어도 큰 문제 없음
  - "진짜 보호해야 하는 키"는 14주차에서 따로 학습 — 오늘은 부담 X
  - 키 = 한 줄짜리 긴 문자열, 비밀번호 아님 (오늘 기준)
- **시각 요소**:
  - 신분증 아이콘 + 자판기 옆 "회원 전용" 표시
  - 3단계 카드: ① 회원가입 → ② 키 복사 → ③ Claude Code에 붙여넣기
  - 우측 안내박스: "키 잃어버려도 새로 발급 가능 / 14주차에 더 깊이"
- **강사 노트**: "키 들으면 무섭게 느껴지는데, 오늘 쓰는 무료 키는 그냥 출입증이에요. 14주차에 진짜 비밀번호급 키를 다뤄요."

### 슬라이드 6 — 실습 ①: 키 없는 무료 데이터 받아오기 (고양이 이미지)
- **유형**: 실습
- **goal**: 키 없이도 동작하는 가장 쉬운 외부 데이터를 받아 페이지에 띄운다.
- **핵심 토픽**:
  - 사용 서비스: thecatapi.com (고양이 이미지) / quotable.io (랜덤 명언)
  - 키 없이 즉시 호출 가능 — "처음 성공 경험" 만드는 단계
  - 새로고침 버튼 → 다시 받아오기 동작 확인
  - "데이터를 받았다 / 화면에 떴다"를 직접 눈으로 확인
  - 실패 케이스 미리 보기: 오타·인터넷 끊김 시 빈 화면
- **시각 요소**:
  - 상단 결과 미리보기 (고양이 사진 + "새로고침" 버튼 UI)
  - 좌측 프롬프트 박스:
    ```
    고양이 이미지 API에서 랜덤 이미지를 받아서 페이지에 표시하고,
    새로고침 버튼을 누르면 다시 받아오게 해줘.
    ```
  - 우측 체크리스트: ☐ 페이지 열림 ☐ 이미지 뜸 ☐ 버튼으로 갱신
- **강사 노트**: "이게 진짜 첫 동적 페이지예요. 새로고침 누를 때마다 다른 고양이가 나오면 박수." 빨리 성공시켜 자신감 부여.

### 슬라이드 7 — 실습 ②: API 키로 날씨 카드 만들기 (OpenWeather)
- **유형**: 실습
- **goal**: 무료 키를 발급받아 첫 "키 사용 호출"을 성공시키고 카드 UI로 표시한다.
- **핵심 토픽**:
  - OpenWeatherMap 가입 → 키 발급 (강사 시연)
  - 도시명(서울) → 현재 날씨 데이터(온도·습도·날씨 상태) 받기
  - 카드 UI로 표시: 도시명 · 온도 · 아이콘 · 한 줄 설명
  - 받은 JSON을 어떻게 화면에 꽂는지 흐름 짚기
  - 키 노출 안내: "오늘은 OK, 14주차에 보호 방법 배움"
- **시각 요소**:
  - 좌측 프롬프트 박스:
    ```
    OpenWeatherMap API로 서울 현재 날씨를 받아서
    페이지에 카드로 표시해줘. 내 API 키는 ___.
    ```
  - 우측 결과 카드 모형 (도시 / 22° / 맑음 / 습도)
  - 키 발급 화면 캡처 미니 썸네일
- **강사 노트**: "키 복사 → 프롬프트 빈칸에 붙여넣기. 그 다음은 클로드가 다 합니다. 우리는 결과만 봐요."

### 슬라이드 8 — 실습 ③: 받은 데이터로 검색·필터 붙이기
- **유형**: 실습
- **goal**: 받아온 데이터 배열에 검색창을 연결해 "동적 페이지"의 진짜 맛을 본다.
- **핵심 토픽**:
  - 데이터가 여러 개일 때(배열) → 그 안에서 키워드 매칭
  - 검색창 입력 → 실시간 필터링
  - 정렬 옵션도 한 줄 프롬프트로 추가 가능 (예: 가나다순)
  - "데이터 받아오기"와 "데이터 다루기"는 다른 단계라는 감각
  - 다음 주(10회차) 예고: 받은 데이터를 "저장"하기 시작
- **시각 요소**:
  - 좌측 프롬프트 박스:
    ```
    받은 데이터에 검색창을 추가해줘.
    입력한 키워드가 포함된 항목만 보이도록.
    ```
  - 우측 검색창 UI 모형 (입력 전 → 입력 후 필터링된 결과)
  - 하단 띠: "10회차 예고 — 데이터 저장 시작"
- **강사 노트**: "받아오기만 하면 매번 처음부터 다시 받죠. 다음 주엔 받은 걸 보관하기 시작합니다. 오늘은 일단 받아오기 마스터."
