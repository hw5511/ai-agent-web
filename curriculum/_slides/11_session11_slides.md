### 슬라이드 1 — 표지: 클라우드 DB로 도약

### 슬라이드 2 — 학습 목표 (4)
- (1) Claude Code에 Supabase 연결·프로젝트 (2) 프롬프트로 테이블·페이지 연결 (3) 배포·잠듦 방지 (4) 지난주 로컬 쇼핑몰을 클라우드로(그린)

### 슬라이드 3 — Supabase란
- PostgreSQL 기반 클라우드 DB / 가입 1분, 인터넷 주소로 DB / 무료 플랜 충분 / Claude Code(MCP)로 직접 제어. 그린 "가입만 1분, 코드는 Claude가".

### 슬라이드 4 — 테이블 + 컬럼
- 테이블=엑셀 시트, 컬럼=열, 행=한 줄 / id·created_at 자동 / 예시 guestbook 표. 핵심 "10주차 CSV 표(머리글) = 오늘 만들 클라우드 테이블".

### 슬라이드 5 — CRUD 4종 (개념)
- Create(추가)·Read(조회)·Update(수정)·Delete(삭제) 4카드 / 공통 패턴 "어느 테이블에 무엇을". 그린 "패턴만 익히면 끝 — 코드는 Claude가".

### 슬라이드 6 — 실습 1: Supabase 연결 + 프로젝트 (MCP)
- 단계: MCP 연결(1회) → OAuth 로그인 → "프로젝트 만들어줘" → 비용 확인(무료) → 주소·공개 키 확보
- prompt: "Supabase에 'my-guestbook' 프로젝트를 새로 만들어줘. 리전은 서울로."
- 키 안전: anon 공개 OK / service_role 절대 금지. 그린 "이제 내 전용 클라우드 DB가 생겼다".

### 슬라이드 7 — 실습 2: 테이블 만들고 페이지 연결
- 단계: "guestbook 테이블 만들어줘" → 생성(id·created_at 자동) → "내 페이지 연결해줘" → 코드 자동 → 글 1건 확인
- prompt: "guestbook 테이블(nickname, message) 만들고, 내 방명록 페이지를 거기에 연결해줘."
- 그린 "이제 새로고침해도, 다른 기기에서도 글이 보인다".

### 슬라이드 8 — 실습 3: 로컬 쇼핑몰을 클라우드로 (CEO 지정)
- 지난주 products.csv 쇼핑몰 → Supabase products 테이블로 전환. before/after(로컬 CSV → 클라우드).
- prompt: "지난주 로컬 products.csv 쇼핑몰을 Supabase products 테이블로 옮기고, 페이지가 클라우드에서 상품을 읽게 바꿔줘."
- 그린 "내 컴퓨터가 꺼져도 쇼핑몰은 살아있다".

### 슬라이드 9 — 배포 + 잠듦 방지 (신규)
- Pages 배포 → 진짜 주소 → 무료 DB 7일 미사용 시 잠듦 → 3일마다 핑 GitHub Action. "왜 핑?" 박스(DB 활동 기준, 레포 60일 무커밋 시 Action 멈춤).
- prompt: "내 사이트를 GitHub Pages에 배포하고, 무료 Supabase가 안 잠들게 3일마다 핑 보내는 GitHub Action도 만들어줘."
- 그린 "배포 + 자동 핑 = 24시간 살아있는 사이트".
