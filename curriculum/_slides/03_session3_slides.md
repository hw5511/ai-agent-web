### 슬라이드 3 — 개념 ①: CSS의 4대 영역
- **유형**: 개념
- **goal**: CSS가 다루는 영역을 색·폰트·여백·레이아웃 4가지로 분류해, 디자인이 "감"이 아니라 4개 카테고리의 조합이라는 걸 이해시킨다.
- **핵심 토픽**:
  - 영역 1: **색·배경** (color, background-color) → 첫인상의 70%
  - 영역 2: **폰트·타이포** (font-family, font-size, font-weight) → 신뢰도·분위기
  - 영역 3: **간격·여백** (padding, margin) → 답답함 vs 숨통
  - 영역 4: **레이아웃·배치** (flex, grid) → 가로/세로 정렬, 정돈감
  - 오늘은 1~3번에 집중 (레이아웃은 맛보기)
- **시각 요소**:
  - 2x2 카드 그리드: 각 영역마다 아이콘 + CSS 속성 예시 1~2개
  - 카드 우상단에 오늘 다룰 비중 막대 (색 ████ / 폰트 ███ / 여백 ███ / 레이아웃 █)
- **강사 노트**: "디자인 = 4개 슬롯 채우는 게임. 오늘은 앞 3개를 채워봅시다."

### 슬라이드 4 — 개념 ②: CSS 클래스란 (전면 교체)
- **유형**: 개념
- **goal**: CSS도 스타일을 표시하는 마크업 언어이며, 클래스는 스타일에 이름을 붙여 재사용하는 것임을 이해한다.
- **핵심 토픽**:
  - CSS도 '표시(markup)'하는 언어 — HTML은 '의미'를, CSS는 '스타일'을 표시한다
  - **클래스 = "여기부터 여기까지 글자를 이런 색·이런 크기로" 정리해 이름 붙여두는 것**
  - 한 번 정의한 클래스를 여러 요소에 재사용
  - 글자뿐 아니라 박스·버튼 등 시각 요소까지 디자인
- **시각 요소**:
  - 좌측 개념 글머리 4개 + 그린 핵심 한 줄("스타일에 '이름표'를 붙여 재사용")
  - 우측 카드: `.btn` 클래스 한 번 정의 → 동일한 버튼 3개 재사용 ("같은 클래스 → 어디서나 똑같이")
- **강사 노트**: "색·폰트를 매번 따로 말하지 말고, 한 번 '이름표(클래스)'를 붙여두면 그 다음부터는 이름만 부르면 돼요."
- **참고**: 옛 '색상 유형과 분위기'는 폐지 — 색 내용은 슬라이드 3(4대 영역)과 슬라이드 6(색상 실습)에 흡수.

### 슬라이드 5 — 개념 ③: 폰트 3종 분류 + Google Fonts
- **유형**: 개념
- **goal**: Serif / Sans-Serif / Display 3분류로 폰트 인상을 정리하고, Google Fonts가 무료로 무한 폰트를 빌려주는 "옷장"이라는 걸 소개한다.
- **핵심 토픽**:
  - **Serif**: 삐침 있음 (Noto Serif) → 고급, 신뢰, 매거진
  - **Sans-Serif**: 깔끔 직선 (Inter, Noto Sans) → 현대적, 테크, 가독성
  - **Display**: 강렬·장식적 → 임팩트, 로고, 헤드라인 전용
  - Google Fonts = 무료 폰트 1,500개 옷장, `<link>` 한 줄로 가져옴
  - 한글+영문 조합 공식: **Noto Sans KR (한글) + Inter (영문)** = 안전한 첫 조합
- **시각 요소**:
  - 3분할 카드: 각 폰트 분류별 "Hello / 안녕" 샘플 텍스트 큼직하게
  - 우측에 Google Fonts 로고 + `<link rel="stylesheet" href="...">` 코드박스 1줄
  - 하단에 "오늘 쓸 폰트" 박스: Noto Sans KR + Inter
- **강사 노트**: "폰트 이름 외울 필요 없어요. 'Google Fonts에서 Noto Sans KR 적용해줘' 한 줄이면 끝."

### 슬라이드 6 — 실습 ①: 색상 테마 적용 (다크 테크)
- **유형**: 실습
- **goal**: 2주차에 만든 HTML 페이지에 "다크 테크" 색상 테마를 Claude Code 자연어 지시로 적용해, CSS 첫 변화를 즉시 눈으로 확인한다.
- **핵심 토픽**:
  - Step 1: Claude Code에 2주차 폴더 열기
  - Step 2: 프롬프트 그대로 복붙
    > "2주차에 만든 페이지에 다크 테크 색상 테마 적용해줘. 배경 #0f172a, 텍스트 흰색, 포인트 #38bdf8."
  - Step 3: 새로 생긴 `style.css` 파일 확인 (Claude가 `<link>`까지 연결해줌)
  - Step 4: 브라우저 새로고침 → Before/After 즉시 비교
  - 자주 나오는 막힘: CSS 파일이 연결 안 됐을 때 → "style.css가 HTML에 link 됐는지 확인해줘"
- **시각 요소**:
  - 좌측: 프롬프트 코드박스 (복붙용 강조)
  - 우측: Before(기본 흰 배경) → After(짙은 남색 + 청록 포인트) 비교 스크린샷 자리
  - 하단 팁 박스: "색상 코드 모르면 '다크 테크 분위기로'만 써도 됨"
- **강사 노트**: 첫 실습은 다 함께 동시 진행. 5분 안에 끝나야 함. 막힌 사람 손 들기.

### 슬라이드 7 — 실습 ②: Google Fonts로 폰트 갈아끼우기
- **유형**: 실습
- **goal**: Google Fonts CDN `<link>` 한 줄과 `font-family` 한 줄로, 한글+영문 폰트가 동시에 바뀌는 경험을 시킨다.
- **핵심 토픽**:
  - 프롬프트 그대로 복붙
    > "위 페이지에 Google Fonts의 Noto Sans KR(한글) + Inter(영문) 폰트 적용해줘."
  - Claude가 자동으로 하는 일:
    - `<head>`에 Google Fonts `<link>` 2개 추가
    - `body { font-family: 'Inter', 'Noto Sans KR', sans-serif; }` 적용
  - 폰트 우선순위: 영문 폰트를 앞에 두면 영문은 Inter, 한글은 자동으로 Noto Sans KR로 떨어짐
  - 확인 포인트: 한글·영문 두 곳 모두 폰트가 바뀌었는지 새로고침해서 보기
- **시각 요소**:
  - 좌측: 프롬프트 박스
  - 우측: 적용 전(기본 시스템 폰트) vs 적용 후(Inter+Noto Sans KR) 같은 문장 비교
  - 작은 박스: Google Fonts 사이트 로고 + "공짜·상업 사용 가능"
- **강사 노트**: 한글이 깨지면 Noto Sans KR이 안 불러와진 경우. "한글 폰트 다시 적용해줘" 한 마디면 됨.

### 슬라이드 8 — 개념 ③: 디자인 시스템과 컴포넌트
- **유형**: 개념
- **goal**: 클래스를 모으면 디자인 시스템이 되고, 반복되는 UI를 묶으면 컴포넌트가 된다는 것을 이해한다.
- **핵심 토픽**:
  - **디자인 시스템** = 색·간격·글자 크기의 '일관된 규칙' 묶음 (한 번 정하면 페이지 전체 통일)
  - **컴포넌트** = 버튼·카드처럼 반복되는 UI를 클래스로 묶어 재사용하는 단위
  - 한 곳(클래스)만 고치면 전부 바뀐다 → 일관성 + 속도
- **시각 요소**: 좌 디자인 시스템(색·간격·타입 토큰) / 우 컴포넌트(버튼·카드) 2카드 + 그린 핵심 한 줄
- **강사 노트**: "클래스 하나하나가 모이면 '우리 페이지만의 규칙'이 돼요. 그게 디자인 시스템이고, 자주 쓰는 묶음이 컴포넌트예요." (이 회차의 컴포넌트는 재사용하는 CSS 클래스 묶음 수준 — 진짜 React 컴포넌트는 후속 회차)

### 슬라이드 9 — 실습 ③: 컴포넌트 만들어 재사용
- **유형**: 실습
- **goal**: 버튼·카드를 클래스로 묶어 컴포넌트로 만들고 여러 곳에 재사용한다.
- **핵심 토픽**:
  - 프롬프트: **"작품 갤러리 항목을 .card 컴포넌트로 만들고, 버튼은 .btn 클래스로 통일해줘."**
  - 자주 쓰는 버튼을 .btn 클래스로 정의
  - 작품 카드(이미지+제목+설명)를 .card 클래스로 묶기
  - 같은 클래스를 여러 곳에 재사용 → 색·간격 한 번에 통일
  - 클래스 한 곳만 고쳐 전체가 바뀌는지 확인
- **시각 요소**: STEPS 글머리 4개 + 우측 프롬프트 박스 + 그린 핵심 한 줄("한 번 만들어 여러 번 — 그게 컴포넌트")
- **강사 노트**: "한 번 잘 만든 .card를 갤러리 전체에 재사용해요. 색 하나 바꾸고 싶으면 .card 한 곳만 고치면 끝."

### 슬라이드 10 — 핵심 정리: 여백 트기 & Before/After
- **유형**: 정리
- **goal**: 마지막 여백·정렬 정리로 페이지를 "숨통 트인" 상태로 마무리하고, 2주차 vs 3주차를 나란히 비교하며 오늘 배운 것(색·폰트·클래스/컴포넌트·여백)을 정리한 뒤 다음 주(JavaScript) 예고로 닫는다.
- **핵심 토픽**:
  - 마지막 실습 프롬프트
    > "페이지가 답답해 보여. 섹션 사이 여백을 넉넉히 주고 가운데 정렬해줘."
  - 적용되는 CSS 속성: `padding`(안쪽 여백), `margin`(바깥 여백), `max-width` + `margin: 0 auto`(가운데 정렬)
  - **오늘 배운 것 3줄 정리**:
    1. 색 — 자연어로 테마 지시 (다크 테크, 웜, 미니멀…)
    2. 폰트 — Google Fonts + 한글/영문 조합 한 줄
    3. 여백 — padding·margin으로 답답함 해소
  - Before(2주차 흰 배경 + 시스템 폰트 + 빡빡) → After(다크 테크 + Inter/Noto + 여백) 비교
  - **다음 주(4회차) 예고**: JavaScript — "버튼 누르면 반응하는 페이지"
  - 숙제: 색상 테마를 "웜" 또는 "미니멀"로 바꿔서 한 버전 더 만들어오기
- **시각 요소**:
  - 상단 절반: Before vs After 풀사이즈 비교 (2주차 페이지 / 3주차 리디자인 페이지)
  - 하단 절반 좌측: "오늘의 3줄 요약" 카드
  - 하단 절반 우측: "다음 주 예고" 카드 + 숙제 박스
  - 페이지 진행 점 ●●●●●●●● 모두 강조 (회차 완료 표시)
- **강사 노트**: 시간 남으면 학생 화면 2~3개 캡처해서 화면 공유. "같은 프롬프트인데 다 다르게 나오죠?" 로 개성·재미 강조하고 마무리.

  - 컴포넌트는 3주차 눈높이로 "재사용하는 CSS 클래스 묶음(버튼·카드)" 수준 (React 컴포넌트는 후속 회차)
- **실습 프롬프트 3개**: 모두 자연어, 코드 직접 입력 0줄 — "코딩 zero" 학생 프로파일 부합
- **외부 의존성**: Google Fonts CDN (`fonts.googleapis.com`) 1개, 별도 라이브러리 없음
- **표현 가이드 준수**: 금지어("백엔드·풀스택·서버 사이드·API 서버·프로덕션") 미사용 확인 완료
- **누적 효과**: 2주차 HTML 뼈대를 그대로 재활용 → "내가 만든 것이 진짜 변했다"는 성취감 극대화
