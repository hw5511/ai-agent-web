### 슬라이드 3 — 개념: HTML이란 무엇인가
- **유형**: 개념
- **goal**: HTML = 웹페이지의 뼈대라는 직관을 비유로 잡는다
- **핵심 토픽**:
  - HTML = HyperText Markup Language (외울 필요 X)
  - 비유: 건물의 철근 구조 — 보이지 않지만 모든 화면의 기초
  - 브라우저가 페이지를 열 때 가장 먼저 읽는 파일
  - 뼈대만 있으면 검은 글씨 페이지 (그게 정상)
  - 뼈대 → 옷(CSS) → 움직임(JS) 순서로 쌓인다
- **시각 요소**:
  - 다이어그램: 건물 철근 ↔ HTML 코드 좌우 매핑
  - 하단 3단 스택: HTML(뼈대) / CSS(옷) / JS(움직임) — 오늘은 맨 아래 칸만 강조
- **강사 노트**: "지금 보는 모든 사이트는 다 이 검은 글씨에서 시작했어요. 네이버도, 인스타도."

### 슬라이드 4 — 개념: 시맨틱 태그 5종
- **유형**: 개념
- **goal**: header·main·section·article·footer 5종의 의미를 한 번에 익힌다
- **핵심 토픽**:
  - **header**: 페이지 상단 (로고·메뉴 자리)
  - **main**: 본문 전체를 감싸는 컨테이너
  - **section**: 의미 단위 영역 (소개 영역, 작품 영역 등)
  - **article**: 독립적으로 떼어내도 말이 되는 글 한 덩어리
  - **footer**: 페이지 하단 (저작권·연락처 자리)
- **시각 요소**:
  - 표 형식: 태그 / 의미 / 위치 / 예시 4열
  - 우측: 페이지 와이어프레임에 5개 영역 색깔로 표시
- **강사 노트**: "외우려 하지 마세요. Claude가 알아서 써줍니다. 다만 우리가 '이 영역은 footer로 빼줘' 정도는 말할 수 있어야 해요."

### 슬라이드 5 — 실습 1: 첫 뼈대 생성
- **유형**: 실습
- **goal**: "스타일 없이 구조만" 지시법으로 첫 HTML 뼈대를 만든다
- **핵심 토픽**:
  - 프롬프트: **"내 이름, 직업, 소개글, 연락 버튼이 있는 랜딩페이지 HTML 뼈대를 만들어줘. 스타일은 없이 구조만."**
  - "스타일 없이"가 핵심 — CSS 빠진 순수 구조가 나옴
  - 구체 항목 명시(이름·직업·소개·버튼) → Claude가 시맨틱 태그로 자동 배치
  - 결과 화면: 검은 글씨, 흰 배경 — 당황 금지
  - 파일 위치 확인: `index.html`
- **시각 요소**:
  - 코드박스: 위 프롬프트 강조 박스
  - 우측: 결과 미리보기 목업 (검은 글씨 페이지)
  - 하단 팁박스: "못생긴 게 정상입니다"
- **강사 노트**: "혹시 Claude가 멋대로 스타일 넣어버리면 '스타일 다 빼고 구조만 다시'라고 말하세요."

### 슬라이드 6 — 개념: 구조와 디자인 분리
- **유형**: 개념
- **goal**: 왜 처음부터 디자인을 안 넣고 뼈대만 만들었는지 이해한다
- **핵심 토픽**:
  - 같은 뼈대 → 다양한 스타일 갈아끼우기 가능
  - 수정할 때 한쪽만 건드리면 됨 (구조 따로, 디자인 따로)
  - Claude에게 지시할 때도 "구조 수정"과 "스타일 수정"을 분리해서 말하기
  - 다음 주에 이 뼈대 그대로 두고 CSS만 입힐 예정
  - 실무에서도 동일한 원칙
- **시각 요소**:
  - 다이어그램: 1개 뼈대 → 3가지 스타일 변형 (마네킹에 옷 갈아입히기)
  - 비교 표: 뼈대만 수정 / 디자인만 수정 / 둘 다 수정
- **강사 노트**: "오늘 뼈대를 잘 잡아두면 다음 주 CSS 회차가 매우 편해집니다."

### 슬라이드 8 — 실습 3: 링크와 이미지
- **유형**: 실습
- **goal**: a 태그·img 태그로 외부 자원을 페이지에 연결한다
- **핵심 토픽**:
  - 프롬프트: **"작품 갤러리에 임시 이미지(loremflickr) 4개 넣고 각각 외부 사이트로 가는 링크를 달아줘."**
  - `loremflickr.com/{w}/{h}/{키워드}` — 키워드 기반 임시 이미지 서비스
  - a 태그 = 링크 / img 태그 = 이미지
  - 이미지 4개에 각각 다른 키워드를 줄 수 있음 (food, travel, design 등)
  - 결과: 검은 글씨 페이지에 이미지 4개 + 클릭하면 이동
- **시각 요소**:
  - 코드박스: 프롬프트 + loremflickr URL 패턴 설명
  - 우측: 이미지 4개가 박힌 결과 화면 목업
  - 하단 팁박스: "키워드 바꿔보며 마음에 드는 이미지 찾기"
- **강사 노트**: "이제 페이지에 색이 좀 생겼지요. 다음 주에 CSS로 본격 디자인 들어갑니다."
