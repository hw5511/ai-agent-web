### 슬라이드 7 — git, 5분 압축
- **유형**: 개념
- **goal**: git을 깊이 가르치지 않고, "변경 이력 + 백업 + 배포 통로"라는 3가지 기능만 인지시킨다.
- **핵심 토픽**:
  - git = 내 작업물의 타임머신 (변경 이력)
  - GitHub = 그 타임머신을 인터넷에 올려두는 곳 (백업)
  - GitHub Pages = 그 폴더를 그대로 웹사이트로 띄워주는 무료 호스팅
  - 우리는 직접 명령어 안 침 — Claude Code가 다 함
- **시각 요소**: 3단 다이어그램 (내 노트북 → GitHub 레포 → 공개 URL) 화살표로 연결 / 각 단계 아래 한 줄 설명
- **강사 노트**: "여기 5분 이상 쓰지 마세요. 학생이 'git 어렵다' 느끼면 실패. 그냥 통로라고만 하세요."

### 슬라이드 8 — GitHub CLI(gh)와 Pages, 그림으로 이해하기
- **유형**: 개념
- **goal**: "배포해줘" 한 줄이 내부에서 어떤 일을 하는지 큰 그림만 보여준다.
- **핵심 토픽**:
  - `gh repo create` → 인터넷에 빈 폴더 만들기
  - `git push` → 내 파일 그쪽으로 복사
  - GitHub Pages 설정 → 그 폴더를 웹사이트로 자동 변환
  - 토큰(Personal Access Token) = 내 GitHub 출입증 (1회차에 미리 발급)
- **시각 요소**: 좌→우 4스텝 파이프라인 다이어그램 (레포 생성 → push → Pages on → URL 생성) / 각 스텝 위에 작은 gh 명령어 라벨
- **강사 노트**: "명령어는 외울 필요 없어요. 'Claude한테 시킨다'는 감만 잡으세요."

### 슬라이드 9 — 실습 2: "배포해줘" 한 줄로 끝
- **유형**: 실습 (클라이맥스)
- **goal**: 학생 모두가 본인 페이지의 공개 URL을 손에 쥔다.
- **핵심 토픽**:
  - 사전 확인: GitHub 토큰 발급되어 있나? (1회차 사전과제)
  - 실습 프롬프트: `이 페이지를 GitHub 레포 만들고 GitHub Pages로 배포해줘. 레포 이름은 my-portfolio.`
  - Claude Code가 자동으로: 레포 생성 → push → Pages 활성화 → URL 회신
  - 회신된 URL 휴대폰으로 열어보기 (감동 포인트)
- **시각 요소**: 큰 코드박스에 프롬프트 한 줄 강조 / 아래에 "받게 될 URL 형태" 예시 `https://hw5511.github.io/my-portfolio` / 우측 모바일 mockup 아이콘
- **강사 노트**: 토큰 만료/권한 에러 빈발 — 강사가 미리 1:1 도와줄 준비. "여기서 5분 안에 URL 못 받으면 강사 호출하세요."
