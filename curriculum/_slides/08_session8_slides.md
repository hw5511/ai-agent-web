### 슬라이드 3 — React가 뭔가
- **유형**: 개념
- **goal**: React 핵심 = 컴포넌트를 레고 블록 비유로 이해
- **핵심 토픽**:
  - 1~7주 방식: HTML/CSS/JS 한 파일에 다
  - React 방식: **컴포넌트**로 쪼개서 조립
  - 컴포넌트 = 재사용 가능한 UI 조각 (Hero, Card, Button…)
  - JSX = HTML처럼 생겼지만 JS 파일 안에서 쓴다
- **강사 노트**: "직접 코드 안 써도 됨. Claude가 다 짜줌. 컴포넌트 = 레고 블록만 기억."

---

### 슬라이드 4 — React UI 라이브러리
- **유형**: 개념
- **goal**: MUI·shadcn/ui·Chakra를 "이미 만들어진 레고"로 소개하고 차이를 직관적으로 비교
- **핵심 토픽**:
  - UI 라이브러리 = 이미 만들어진 컴포넌트 세트
  - **MUI** (Material UI): Google Material Design 기반. 완성도↑ 대기업 느낌 ⭐ 오늘 선택
  - **shadcn/ui**: 코드 복사 방식. 커스터마이징 자유도 최고. 최신 트렌드
  - **Chakra UI**: 심플·초보자 친화·가독성↑
- **강사 노트**: "셋 다 좋음. 오늘은 MUI — 강의 웹앱(vibe-web)이 이미 MUI 실제 사례라서."

---

### 슬라이드 5 — 우리 스택: MUI
- **유형**: 개념
- **goal**: vibe-web이 실제 MUI + React + Vite 사례임을 보여주며 오늘 스택 확정
- **핵심 토픽**:
  - vibe-web = 이 강의 웹앱. React + Vite + MUI로 만들어 배포 중
  - 오늘 포트폴리오도 같은 스택
  - Vite = 빠른 개발 서버 (`npm run dev` 즉시 뜸)
  - 스택: **Vite + React + MUI**
- **강사 노트**: "강사 본인이 MUI로 만든 실제 사이트가 vibe-web. 같은 방식으로 포트폴리오 만듭니다."
