# Session 10 슬라이드 목차 — 데이터 저장 (서버 + CSV)

> **회차 개요**: 2시간 / 심화 트랙 Part 2 / "로컬 서버 + CSV 저장" 핵심
> **회차 끝 학생 상태**: 내 컴퓨터에 Flask 서버를 켜고, 폼 입력이 guestbook.csv에 줄로 쌓이며, 주어진 상품목록(products.csv)으로 로컬 쇼핑몰까지 만든 상태
> **누적 위치**: 9주(데이터 가져오기) → **10주(로컬 서버 + CSV 저장)** → 11주(Supabase 클라우드 DB)
> **재구성 (CEO 2026-05-26)**: 옛 LocalStorage 흐름 폐기 → 로컬 Flask 서버 + CSV 파일 DB로 전환. 비개발자가 "데이터가 저장되는 걸" 엑셀로 직접 보는 것이 목적이라 CSV 채택. 스키마 설명은 유지. 전부 로컬(배포 없음).

### 슬라이드 1 — 표지: 데이터를 저장하다
- **유형**: 표지
- **goal**: 내 컴퓨터에 작은 서버를 켜고 CSV 파일에 글이 쌓이는 방명록을 갖게 된다는 기대감
- **핵심**: Session 10 · 심화 Part 2 · 2시간 / 키워드 서버·localhost·CSV / 한 줄 "내 컴퓨터에 작은 서버를 켜고, CSV 파일에 글을 남긴다"

### 슬라이드 2 — 학습 목표
- **유형**: 학습목표
- **목표 3**: (1) 데이터를 표(스키마)로 설계 (2) 내 컴퓨터에 서버를 켜고 localhost로 열기 (Flask · app.py) (3) 폼 입력을 CSV 파일에 저장하고 직접 열어 확인
- **그린 한 줄**: "이론은 짧게, 화면에 보이는 결과는 길게"

### 슬라이드 3 — 개념①: 데이터를 구조화한다는 것
- **유형**: 개념 (유지)
- **핵심**: 줄글 메모 vs 행·열 표 / 표면 검색·필터·정렬·개수 가능 / 행=데이터, 열=종류

### 슬라이드 4 — 개념②: 스키마 = 데이터의 설계도 → CSV 머리글
- **유형**: 개념
- **핵심**: 컬럼 3요소(이름·타입·옵션) / 방명록 예시 스키마(id·name·message·created_at) / 그린 "이 표가 그대로 CSV 파일의 머리글이 된다"

### 슬라이드 5 — 개념③: 서버란? 내 컴퓨터를 작은 서버로
- **유형**: 개념 (신규)
- **핵심**: app.py = 서버를 켜는 실행 파일 / localhost = 127.0.0.1 = 내 컴퓨터 자신 / 서버가 저장·목록 창구(API)를 연다
- **흐름 다이어그램**: 브라우저(localhost:5000) ↓ app.py 서버(API 창구) ↓ guestbook.csv

### 슬라이드 6 — 개념④: CSV가 우리의 데이터베이스
- **유형**: 개념 (신규)
- **핵심**: 첫 줄=머리글(헤더)=스키마 / 한 줄=한 데이터(행) / 폼 제출 시 맨 아래 한 줄 추가 / 엑셀·메모장으로 그냥 열림
- **미리보기**: guestbook.csv 파일 모형 (id,name,message,created_at + 3행)

### 슬라이드 7 — 실습①: 내 페이지의 스키마 그리기 (20분)
- **유형**: 실습
- **prompt**: "내 페이지에 방명록 기능을 추가하고 싶어. 어떤 컬럼(이름·메시지·날짜 등)이 필요한지 표로 정리해줘."

### 슬라이드 8 — 실습②: 서버 켜고 폼 → CSV에 저장 (40분)
- **유형**: 실습
- **단계**: Flask 서버+폼 부탁 → 터미널 실행·localhost 열기 → 입력·제출 → guestbook.csv 새 줄 확인(하이라이트) → 한 번 더 제출
- **prompt**: "방명록 폼(이름·메시지)을 만들고, 제출하면 Flask 서버가 guestbook.csv에 한 줄씩 저장해줘."

### 슬라이드 9 — 실습③: 목록 표시와 삭제 (25분)
- **유형**: 실습
- **단계**: CSV 읽어 카드 목록 표시 → 삭제 버튼 → 누르면 CSV에서도 제거 → 새로고침·CSV 모두에서 확인 → (보너스) 수정
- **함정**: 전부 사라짐("id로 한 줄만 지워줘") / 새로고침하니 다시 나옴(화면만 지웠고 CSV는 그대로)
- **prompt**: "각 카드에 삭제 버튼을 달고, 누르면 CSV에서도 그 줄이 사라지게 해줘."

### 슬라이드 10 — 실습④: 로컬 쇼핑몰 만들기 (30분)
- **유형**: 실습 (신규 · 마무리 캡스톤)
- **단계**: 액션박스 상품목록을 products.csv로 저장 → Flask 서버가 CSV 읽기 → 이미지·이름·가격 카드 그리드 → localhost로 쇼핑몰 확인
- **액션박스**: products.csv (id,name,price,image — 이미지 링크 포함, picsum.photos 무료) 복사/다운로드
- **prompt**: "이 상품목록(products.csv)을 Flask 서버가 읽어서 이미지·이름·가격 상품 카드 쇼핑몰 페이지로 만들어줘."

### 슬라이드 11 — 핵심 정리 & 다음 주 예고
