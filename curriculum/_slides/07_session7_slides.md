- **강사 노트**: "오늘은 '코드 학습'이 아니라 '카탈로그 학습'입니다. 외울 건 5개 이름뿐."

### 슬라이드 3 — 시각 라이브러리 5종 카탈로그
- **유형**: 개념
- **goal**: tsParticles·Typed.js·Three.js·VANTA·Canvas 2D가 각각 무엇을 하는 도구인지 한눈에 구분한다.
- **핵심 토픽**:
  - **tsParticles**: 점·선으로 이루어진 파티클 배경 효과 전문
  - **Typed.js**: 텍스트 자동 타이핑/삭제 반복 (직함·슬로건용)
  - **Three.js**: 진짜 3D 입체 (큐브·구체·모델)
  - **VANTA**: WebGL 기반 풀스크린 배경 (구름·물결·새 떼)
  - **Canvas 2D**: 브라우저 기본 그리기 도구 — "원 + 선 = 모든 효과"
- **강사 노트**: "외울 것은 '어떤 효과 = 어떤 라이브러리' 매칭뿐. 코드는 Claude가 씁니다. 오늘 이 5종을 하나씩 다 실습합니다."

### 슬라이드 4 — 왜 CDN 한 줄이면 다 끝나는가
- **유형**: 개념
- **goal**: 라이브러리가 페이지에 붙는 원리(CDN 한 줄 + 호출 한 블록)를 직관적으로 이해한다.
- **핵심 토픽**:
  - 라이브러리 = "남이 미리 짜둔 코드 묶음"
  - CDN 링크 = 그 묶음을 인터넷에서 바로 불러오기 (설치 없음)
  - HTML `<head>`에 `<script src="...">` 한 줄 → 사용 준비 완료
  - 호출 코드는 Claude가 생성해줌 → 우리는 "어디에 어떤 효과" 지시만
- **강사 노트**: "설치·세팅 공포 해소 슬라이드. CDN 한 줄 = 설치 끝."

### 슬라이드 5 — 좋은 프롬프트 4요소 (대상·스타일·수치·범위)
- **유형**: 개념
- **goal**: 시각 효과를 의도대로 뽑아내는 프롬프트 공식(4요소)을 학습한다.
- **핵심 토픽**:
  - **대상**: "히어로 섹션 배경에", "직함 자리에" — 어디에 적용할지
  - **스타일**: "흰 점이 천천히 떠다니는", "네온 파란 와이어프레임" — 분위기
  - **수치**: "점 50개", "3초 간격" — 양과 속도
  - **범위**: "마우스에 반응", "스크롤 시 멈춤" — 상호작용 경계
  - 4요소를 다 채울수록 재시도 횟수가 줄어든다
- **강사 노트**: "이번 회차 가장 중요한 슬라이드. 모든 실습에서 4요소 체크하며 진행. 각 실습 슬라이드의 프롬프트 예시가 이 4요소를 담고 있음."

### 슬라이드 6 — 실습 1 · tsParticles로 히어로 배경 살리기
- **유형**: 실습
- **goal**: tsParticles를 활용해 히어로 섹션 배경에 인터랙티브 파티클 효과를 추가한다.
- **핵심 토픽**:
  - 단계: CDN 추가 → 프롬프트 복붙·새로고침 → 점 개수·색·속도 확인 → 대비 약하면 배경 어둡게
  - 다크 배경 + 흰 점 조합이 가장 안정적
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 섹션 배경에 tsParticles 파티클 효과 추가해줘. 흰 점이 천천히 떠다니고 마우스에 반응."
- **시각 요소**: 좌 단계 글머리 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("다크 배경 + 흰 점이 가장 잘 보인다")
- **강사 노트**: "처음엔 기본값으로 띄우고, 두 번째 시도부터 수치 조정."

### 슬라이드 7 — 실습 2 · Typed.js로 직함 타이핑 효과
- **유형**: 실습
- **goal**: Typed.js로 히어로 직함 자리에 자동 타이핑/삭제 반복 애니메이션을 적용한다.
- **핵심 토픽**:
  - 단계: CDN 추가 → 보여줄 문구 목록 정하기 → 프롬프트 복붙·새로고침 → 커서·속도·반복 조정
  - 포트폴리오 직함·랜딩 슬로건에 즉시 활용 가능
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 직함 자리에 Typed.js로 '웹 개발자', 'UI 디자이너', 'Claude 전문가' 순서로 타이핑."
- **시각 요소**: 좌 단계 글머리 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("문구 목록만 바꾸면 — 누구의 직함이든 OK")
- **강사 노트**: "한국어 단어 길이가 들쭉날쭉하면 어색함. 비슷한 글자 수로 통일 권장."

### 슬라이드 8 — 실습 3 · Three.js로 3D 회전 큐브 (+ Sketchfab)
- **유형**: 실습
- **goal**: Three.js의 Scene·Camera·Renderer 개념을 체감하며 회전하는 3D 큐브를 배치하고, Sketchfab에서 받은 3D 모델로 교체해본다.
- **핵심 토픽**:
  - Three.js 3종 세트: Scene(무대) · Camera(시점) · Renderer(화면)
  - 단계: CDN 추가 → 큐브 자리·색·재질·회전 속도 지시 → 응용으로 Sketchfab 모델 교체
  - **Sketchfab 액션**: 무료 3D 모델(.glb)을 내려받아 큐브 대신 페이지에 올릴 수 있다
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 오른쪽에 Three.js로 네온 파란 와이어프레임 큐브가 천천히 회전하도록."
- **액션 버튼**: Sketchfab (https://sketchfab.com/) — 무료 3D 모델 다운로드
- **시각 요소**: 상단 Scene·Camera·Renderer 3카드 / 좌 단계 글머리 / 우 프롬프트 예시 박스(#f9fafb, Sketchfab 안내 포함) + 그린 핵심("무대·시점·화면 3종 세트 — 외울 필요 없이 '있다'는 것만")
- **강사 노트**: "Scene·Camera·Renderer는 '있다는 것만' 인지. Sketchfab에서 마음에 드는 모델 받아 큐브 대신 올려보면 학생들이 가장 신기해함."

### 슬라이드 9 — 실습 4 · VANTA로 움직이는 배경 (CEO 2026-05-26 신설)
- **유형**: 실습
- **goal**: VANTA로 히어로 섹션에 움직이는 풀스크린 배경을 거의 코드 없이 추가한다.
- **핵심 토픽**:
  - 단계: VANTA CDN 추가 → 배경 깔 섹션(히어로) 지정 → 프롬프트 복붙·새로고침 → 색·속도·효과 종류 조정
  - WebGL 기반 풀스크린 배경(물결·구름·네트 등)을 짧은 호출로
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 배경에 VANTA로 움직이는 물결(WAVES) 효과 깔아줘. 어두운 톤으로."
- **시각 요소**: 좌 단계 글머리 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("코드 거의 없이 — 배경 전체가 살아 움직인다")
- **강사 노트**: "VANTA는 효과 종류(WAVES/FOG/NET 등)만 바꿔도 분위기가 확 달라짐. 텍스트 가독성을 위해 어두운 톤 권장."

### 슬라이드 10 — 실습 5 · Canvas로 직접 그리기 (CEO 2026-05-26 신설)
- **유형**: 실습
- **goal**: Canvas 2D로 마우스를 따라가는 트레일 같은 그림을 화면에 직접 그린다.
- **핵심 토픽**:
  - 단계: 전체 화면 캔버스 깔기 → 그릴 대상(마우스 트레일) 정하기 → 프롬프트 복붙·새로고침 → 선 두께·색·사라지는 속도 조정
  - Canvas = 라이브러리 없이도 "원 + 선"으로 모든 효과의 바탕
- **프롬프트 예시(슬라이드 내 박스)**: "Canvas로 마우스를 따라다니는 부드러운 선(트레일) 효과를 배경에 그려줘. 천천히 사라지게."
- **시각 요소**: 좌 단계 글머리 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("빈 캔버스 = 무엇이든 직접 그릴 수 있는 자유")
- **강사 노트**: "Canvas는 라이브러리가 아니라 브라우저 기본 도구. '직접 그린다'는 감각만 체험시키면 충분."
