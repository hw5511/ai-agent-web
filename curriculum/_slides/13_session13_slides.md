### 슬라이드 3 — 개념 ①: 도메인이란 무엇인가
- **유형**: 개념
- **goal**: 도메인이 "사람이 읽기 좋은 인터넷 주소"라는 사실을 비유로 각인시킨다.
- **핵심 토픽**:
  - IP 주소(예: 185.199.108.153) vs 도메인(example.com)
  - 도메인 = "내 가게 간판" / IP = "건물의 GPS 좌표"
  - 사람은 간판을 보고, 기계는 좌표를 본다
  - `.com` `.kr` `.shop` `.dev` 같은 끝부분 = TLD (Top-Level Domain)
  - 도메인은 "소유"가 아니라 "1년 단위 임대"
- **시각 요소**:
  - 가게 일러스트: 간판(도메인) ↔ 지도 좌표(IP) 화살표
  - example.com을 점선으로 쪼개서 보여주는 분해 다이어그램 (`내이름` + `.com`)
  - 작은 표: TLD별 평균 가격 ($10~15/년 / 한국 .kr 가격 따로 표기)
- **강사 노트**:
  - "왜 IP를 그냥 안 쓰냐"는 질문이 자주 나옴 → "외울 수 있냐"고 되묻기. 임대 개념도 짧게 — "갱신 안 하면 다른 사람이 가져갈 수 있어요."

### 슬라이드 4 — 개념 ②: 도메인은 어디서 사나 (가비아 vs 해외)
- **유형**: 개념
- **goal**: 도매상 격인 등록업체(레지스트라) 3곳을 비교해 학생이 "왜 오늘 가비아인지" 납득하게 한다.
- **핵심 토픽**:
  - 가비아: 한국어 UI / 카드·계좌이체 / 한국 .kr 강점 → 오늘 채택
  - Namecheap: 영문 / 가격 저렴 / 해외 결제카드 필요
  - Cloudflare Registrar: 원가에 가까운 가격 / 영문 / 개발자 친화
  - 어디서 사든 도메인 자체는 동일 — "어느 부동산 가서 같은 집을 계약하느냐"의 차이
  - 평균 가격대: .com 약 1.2~1.8만원 / .shop·.site 더 저렴 / .kr 별도
- **시각 요소**:
  - 3열 비교 표: UI 언어 / 결제 / 가격 / 추천 대상
  - 가비아 칸에 별표 + "오늘 우리는 여기" 라벨
- **강사 노트**:
  - 학생이 이미 Namecheap 계정이 있다면 그쪽으로 가도 결과는 같다고 알려주되, 오늘 수업 진행은 가비아 기준임을 명확히. 영어 두려운 학생을 안심시키는 슬라이드.

### 슬라이드 5 — 개념 ③: DNS 레코드 (A 레코드와 CNAME)
- **유형**: 개념
- **goal**: 다음 실습에서 입력할 A 레코드·CNAME이 무엇을 의미하는지 미리 그림으로 이해시킨다.
- **핵심 토픽**:
  - DNS = "도메인 → IP 변환 전화번호부"
  - A 레코드: 도메인을 IP 주소로 직접 연결 (예: `@` → `185.199.108.153`)
  - CNAME 레코드: 도메인을 다른 도메인으로 연결 (예: `www` → `hw5511.github.io`)
  - GitHub Pages는 A 레코드 4개 + CNAME 1개 조합을 요구
  - TTL = "이 정보를 얼마나 캐시할지" (가볍게 언급, 기본값 OK)
  - "주소 정보가 전 세계로 퍼지는 시간" = 몇 분에서 몇 시간
- **시각 요소**:
  - 전화번호부 비유 일러스트 (도메인 = 이름, IP = 전화번호)
  - A 레코드·CNAME 시각 차이: 화살표가 IP로 vs 다른 도메인으로
  - GitHub Pages 공식 IP 4개를 코드박스로 미리 노출 (185.199.108~111.153)
- **강사 노트**:
  - TTL·전파 시간은 "내가 입력해도 즉시 안 보일 수 있다"는 마음의 준비용으로만 가볍게. 깊이 들어가지 말고 "주소 정보가 전 세계로 퍼지는 시간이 필요해요" 한 마디로 마무리.

### 슬라이드 6 — 실습 ①: 가비아에서 내 도메인 구매하기
- **유형**: 실습
- **goal**: 학생이 본인 이름·브랜드 도메인을 직접 검색·결제해 "내 소유" 상태를 만든다.
- **핵심 토픽**:
  - 가비아 가입 (이메일 인증)
  - 메인 검색창에 원하는 이름 입력 → 사용 가능 여부 확인
  - .com이 비싸거나 선점됐다면 .shop / .site / .kr 대안 즉시 시도
  - 1년 등록 / 자동 갱신은 일단 OFF (원하면) / 결제
  - "도메인 등록 완료" 마이페이지에서 확인
  - 소요: 약 10~15분 (결제 포함)
- **시각 요소**:
  - 4단계 스크린샷 플레이스홀더: 검색 → 선택 → 결제 → 마이페이지 확인
  - 우측 팁 박스: "이름이 이미 있다면? → 끝에 `-dev` `-studio` 붙여보기"
  - 학생 직접 진행 안내 (Claude Code 프롬프트 없음 — 본인이 직접 클릭)
- **강사 노트**:
  - 결제 단계에서 멈추는 학생이 가장 많음. 카드 정보·휴대폰 본인 인증 미리 준비하라고 한 번 더 알림. "이름 못 정하겠어요"라는 학생에게는 본인 이름 영문 + 직업/취미 조합 추천.

### 슬라이드 7 — 실습 ②: GitHub Pages와 DNS로 연결하기
- **유형**: 실습
- **goal**: 가비아 DNS 설정에 A 레코드 4개 + CNAME을 입력하고, GitHub 레포 Settings에 도메인을 적어 연결을 완료한다.
- **핵심 토픽**:
  - 가비아 → My가비아 → DNS 관리 진입 경로
  - A 레코드 4개 입력: 호스트 `@`, 값 `185.199.108~111.153`
  - CNAME 입력: 호스트 `www`, 값 `hw5511.github.io`
  - GitHub 레포 → Settings → Pages → Custom domain에 `내도메인.com` 입력 → Save
  - 레포에 `CNAME` 파일이 자동 생성됨 (확인만)
  - 연결 직후 "DNS check in progress" 메시지가 정상이라는 사실 안내
- **시각 요소**:
  - 양쪽 화면 분할 다이어그램: 좌측 가비아 DNS 입력표 / 우측 GitHub Settings 화면
  - 입력값을 그대로 복사할 수 있는 코드박스 5줄 (A×4 + CNAME)
  - Claude Code 프롬프트 박스: "GitHub Pages 도메인 연결 방법 알려줘. 가비아에 A 레코드 4개 입력하고 레포 Settings에 도메인 입력하는 순서대로."
- **강사 노트**:
  - 가장 헷갈리는 지점: "호스트 이름에 뭘 적냐". `@`는 루트(내도메인.com), `www`는 www.내도메인.com이라고 한 번 더 설명. 연결 직후 안 보여도 정상 — 다음 슬라이드에서 기다리는 동안 SSL 진행.

### 슬라이드 8 — 실습 ③ + 정리: SSL(자물쇠) 켜고 서로 공유하기
- **유형**: 실습 + 정리 (통합)
- **goal**: GitHub Pages 자동 SSL을 활성화해 https:// 자물쇠를 켜고, 완성된 본인 도메인을 동료에게 공유하며 회차를 마무리한다.
- **핵심 토픽**:
  - GitHub Pages Settings → "Enforce HTTPS" 체크박스 활성화
  - 내부 동작: Let's Encrypt가 인증서를 자동 발급
  - 체크박스가 회색이라면 = 아직 DNS 전파 중 → 5~30분 후 재시도
  - 완료 후 https:// 접속해 자물쇠 확인 → 친구 단톡에 링크 공유
  - 오늘 한 일 한 줄 회고: "나는 이제 .com을 가진 사람"
  - 다음 주(14회차) 예고: Vercel — 더 빠르고 자동화된 호스팅 옵션
- **시각 요소**:
  - 자물쇠 ON/OFF 비교 일러스트 (http vs https)
  - Claude Code 프롬프트 박스: "GitHub Pages에서 내 도메인에 SSL을 적용하고 싶어. Settings에서 어디를 체크해야 하는지 안내해줘."
  - 하단 회고 카드: "오늘 가진 것 / 다음 주 배울 것" 2열
- **강사 노트**:
  - SSL 체크박스 회색이면 멘붕하는 학생 多 → "주소 정보가 전 세계로 퍼지는 시간이 필요하다"고 다시 한 번 안심. 마지막 5분은 학생끼리 도메인 공유 + 박수. wow 모먼트로 회차를 닫는다.
