# Session 13 슬라이드 목차 — 리액트 업그레이드 + 도메인 연결

> **회차 한 줄 요약**: 지금까지 만든 사이트를 리액트와 프리미엄 컴포넌트 라이브러리로 업그레이드하고, 가비아에서 도메인을 사서 GitHub Pages에 연결한 뒤 https까지 켠다.
> **회차 끝 학생 상태**: 컴포넌트 라이브러리로 멋지게 단장한 사이트 + 본인 도메인(.com/.kr 등) 연결 완료.
> **표현 원칙**: 화면·조각(컴포넌트)·도메인·DNS 정도만 사용. 리액트 문법은 가르치지 않음 — "프롬프트로 리액트 버전 다시 만들기". 어려운 개발 용어 지양.
> **구성**: 1부 리액트 업그레이드(슬라이드 3~6) + 2부 도메인 연결(7~10, 옛 8장 step13을 4장으로 압축).

### 슬라이드 3 — 개념 ① 리액트란? 화면을 조각으로 만드는 방식
- **유형**: 개념
- **goal**: 리액트는 화면을 조각(컴포넌트)으로 만드는 방식이며 우리는 프롬프트로 시킨다는 점을 이해한다.
- **핵심 토픽**:
  - 리액트 = 화면을 작은 조각(컴포넌트)으로 나눠 조립
  - 버튼·카드·메뉴를 조각으로 만들어 다시 쓰기
  - 우리는 코드 문법을 안 배우고 클로드에게 시킴
  - 가는 이유 = 멋진 "컴포넌트 라이브러리"를 쓰려고
- **강사 노트**: 리액트 문법(JSX, useState 등)은 절대 가르치지 않음. "조각으로 만든다"는 직관 + "프롬프트로 시킨다"만.

### 슬라이드 5 — 실습 ① 리액트 + 컴포넌트로 업그레이드
- **유형**: 실습
- **goal**: 내 사이트를 리액트 버전으로 다시 만들고 컴포넌트 라이브러리를 적용해 업그레이드한다.
- **핵심 토픽**:
  - 우측 액션박스 프롬프트 복사해 실행
  - 클로드가 사이트를 리액트 버전으로 다시 제작
  - 원하는 컴포넌트 라이브러리 골라 적용
  - 내용은 그대로 두고 모양만 멋지게
- **실습 프롬프트**:
  > 지금까지 만든 내 사이트를 React로 다시 만들어줘. shadcn/ui 컴포넌트를 적용해서 더 깔끔하고 멋지게. 내 글·상품 같은 내용은 그대로 두고 디자인만 업그레이드해줘.
- **강사 노트**: "내용 유지, 디자인만"을 꼭 짚을 것. 리액트 전환은 클로드가 알아서 — 학생은 결과만 확인.

### 슬라이드 6 — 실습 ② 멋진 움직임 더하기
- **유형**: 실습
- **goal**: 호버·스크롤·애니메이션 같은 멋진 움직임을 골라 사이트에 더한다.
- **핵심 토픽**:
  - 마우스 올리면 반응하는 호버 효과
  - 스크롤하면 위쪽 메뉴 숨고 나타나기
  - 내용이 부드럽게 떠오르는 애니메이션
  - 마음에 드는 효과만 한두 가지
- **실습 프롬프트**:
  > 내 사이트에 멋진 움직임을 더해줘. 마우스 올리면 반응하는 호버 효과, 스크롤하면 위쪽 메뉴가 숨고 나타나기, 내용이 부드럽게 떠오르는 애니메이션. 과하지 않게 한두 가지만 넣어줘.
- **강사 노트**: 움직임 과하면 어지러움. 한두 가지로 시작해 확인하며 늘리기.

### 슬라이드 7 — 개념 ③ 도메인이란? 내 사이트의 간판 주소
- **유형**: 개념 (옛 step13 도메인 개념 3장을 1장으로 압축)
- **goal**: 도메인이 무엇이고 어디서 사며 DNS로 어떻게 연결되는지 한 장에 이해한다.
- **핵심 토픽**:
  - 도메인 = 기억하기 쉬운 내 사이트 주소 (내이름.com)
  - 어디서 사나 = 가비아 (한국어·.kr, 1년 단위 임대)
  - DNS = 도메인을 실제 사이트로 안내하는 전화번호부
  - GitHub 연결엔 A레코드 4개 + CNAME 1개가 필요

### 슬라이드 8 — 실습 ③ 가비아에서 도메인 사기
- **유형**: 실습 (학생 직접 진행)
- **goal**: 학생이 본인 이름이나 브랜드 도메인을 직접 검색하고 결제해 내 소유 상태를 만든다.
- **핵심 토픽**:
  - 가비아 가입 + 이메일 인증
  - 원하는 이름 검색해서 사용 가능한지 확인
  - .com이 비싸면 .shop · .site · .kr 대안
  - 1년 등록 결제 후 마이페이지에서 확인
- **사전 준비**: 예산 1년 약 1만원 내외(도메인 종류별 상이), 결제 수단.

### 슬라이드 9 — 실습 ④ GitHub Pages 연결 + 자물쇠
- **유형**: 실습
- **goal**: 가비아 DNS에 값을 넣고 GitHub에 도메인을 등록한 뒤 https 자물쇠까지 켠다.
- **핵심 토픽**:
  - 가비아 DNS에 A레코드 4개 + CNAME(www) 입력
  - GitHub 레포 Settings → Pages → Custom domain에 도메인
  - DNS 전파 기다리기 (10분~몇 시간)
  - Enforce HTTPS 체크 → https 자물쇠 켜짐
- **실습 프롬프트 (도메인 연결)**:
  > 내 GitHub Pages 사이트에 도메인을 연결해줘. 연결할 도메인은 ___. 네가 할 수 있는 GitHub 쪽 설정(Settings의 custom domain, CNAME 파일, Enforce HTTPS)을 먼저 다 해주고, 내가 가비아에서 입력해야 할 DNS 값을 깔끔하게 정리해줘.
- **가비아 DNS 설정값 (복붙용)**:
  ```
  A 레코드 (호스트 @ , 4개 모두):
  185.199.108.153
  185.199.109.153
  185.199.110.153
  185.199.111.153
  CNAME (호스트 www):
  내깃허브아이디.github.io.   (끝에 점 . 필수)
  ```
- **강사 노트**: 가비아는 CNAME 값 끝 점(.) 필수. 자물쇠 회색이면 DNS 전파 대기 중.
