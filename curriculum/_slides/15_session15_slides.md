### 슬라이드 3 — 개념 1: 왜 Vercel 함수에서 호출해야 하나

- **유형**: 개념
- **goal**: 유료 API 키가 클라이언트(브라우저)에 노출되면 안 되는 이유와 안전한 호출 경로를 이해한다
- **핵심 토픽**:
  - OpenAI 키 = 카드와 같은 것. 노출되면 즉시 돈이 빠진다
  - 브라우저 코드에 키를 적으면 누구나 F12로 볼 수 있다
  - Vercel 함수 안에서만 `process.env.OPENAI_KEY`를 읽는다
  - 클라이언트는 Vercel 함수만 호출, 키는 절대 모름
- **시각 요소**:
  - 흐름도: 브라우저 → (호출) → Vercel 함수 → (키 사용) → OpenAI
  - 위험 케이스 vs 안전 케이스 좌우 비교 (X / O 마크)
  - 코드박스: `// 브라우저 X\n// Vercel 함수 O\nconst key = process.env.OPENAI_KEY`
- **강사 노트**: "백엔드 처리"라는 표현 대신 "Vercel 함수에서 처리"로 일관되게 말한다. 키 유출 사고 예시 1줄로 경각심.

### 슬라이드 4 — 개념 2: 오늘 다룰 AI API 3종

- **유형**: 개념
- **goal**: OpenAI/Stability/DeepL 각각이 무엇을 잘하는지, 학생이 어떤 걸 고르면 좋을지 안다
- **핵심 토픽**:
  - **OpenAI (GPT)** — 텍스트 작업 전반: 요약·답변·자기소개 생성
  - **Stability AI** — 이미지 생성: 프롬프트 → 그림
  - **DeepL** — 고품질 번역: 한→영, 영→한
  - 셋 다 무료 크레딧 존재, 카드 등록은 선택
  - 호출 방식은 동일 패턴: "Vercel 함수에서 fetch + 키"
- **시각 요소**:
  - 3열 카드 표: API명 / 잘하는 것 / 입력 예 / 출력 예
  - 하단 공통 패턴 다이어그램: `페이지 입력 → Vercel 함수 → API → 응답`
- **강사 노트**: 셋 다 패턴이 같다는 게 핵심. 하나 익히면 나머지도 Claude Code가 알아서 잘 만들어 준다.

### 슬라이드 5 — 개념 3: 프롬프트 4요소를 API에도 그대로

- **유형**: 개념
- **goal**: 7주차 프롬프트 4요소(대상·스타일·수치·범위)가 AI API 요청에서도 동일하게 결과를 좌우함을 이해한다
- **핵심 토픽**:
  - **대상**: 누구를 위한 답인가 (예: "초등학생도 알게")
  - **스타일**: 톤·말투 (예: "친근한 반말")
  - **수치**: 길이·개수 (예: "3줄로", "5개")
  - **범위**: 다룰 것 / 다루지 말 것 (예: "기술 용어 빼고")
  - "토큰"이란? → API에서 글자 수 비슷한 단위. 길게 쓰면 비용·시간 증가
- **시각 요소**:
  - Before/After 박스: 모호한 프롬프트 vs 4요소 적용 프롬프트
  - 4요소 색상 라벨 (대상=파랑 / 스타일=초록 / 수치=주황 / 범위=빨강)
- **강사 노트**: "토큰"은 단어가 등장할 때마다 "글자 수 비슷한 단위" 표현으로 풀어준다. 길게 쓸수록 응답이 느려지고 무료 크레딧이 빨리 닳는다는 실용 포인트.

### 슬라이드 6 — 실습 1: 텍스트 요약 기능 만들기

- **유형**: 실습
- **goal**: `api/summarize.js`를 만들고 페이지에서 textarea로 글을 입력하면 OpenAI가 3줄로 요약해 돌려주게 한다
- **핵심 토픽**:
  - 사전 준비: Vercel 환경변수 `OPENAI_KEY` 등록 (14주차 복습)
  - Claude Code 프롬프트로 한 번에 생성
  - 결과 페이지: textarea + "요약하기" 버튼 + 결과 영역
  - 동작 확인: 긴 뉴스 본문 붙여넣고 3줄 응답 확인
- **시각 요소**:
  - 화면 와이어프레임 (textarea → 버튼 → 결과 박스)
  - 코드박스(짧게): `// api/summarize.js — OpenAI 호출 골격`
  - Claude Code 프롬프트 박스 (회색 배경)
- **강사 노트**: 프롬프트 — "Vercel 환경변수 OPENAI_KEY 추가했어. api/summarize.js 만들어서 텍스트 입력 받아 OpenAI로 3줄 요약해줘. 페이지에서 textarea+버튼으로 호출."

### 슬라이드 7 — 실습 2: 이미지 생성 기능 붙이기

- **유형**: 실습
- **goal**: Stability AI를 호출하는 `api/generate-image.js`를 만들어 페이지에서 프롬프트 입력 → 이미지 생성 → 화면 표시까지 완료한다
- **핵심 토픽**:
  - Stability 무료 크레딧 가입 + 키 발급
  - Vercel 환경변수 `STABILITY_KEY` 등록
  - Claude Code 프롬프트로 함수 + 페이지 동시 생성
  - 프롬프트 4요소 적용 (예: "수채화 스타일, 정사각형, 강아지 1마리")
- **시각 요소**:
  - 흐름 다이어그램: 프롬프트 입력 → Vercel 함수 → Stability → 이미지
  - 결과 미리보기 모형 (이미지 자리표시자)
  - 코드박스: `// api/generate-image.js 호출부 골격`
- **강사 노트**: 프롬프트 — "api/generate-image.js 만들어서 Stability AI로 이미지 생성해줘. 환경변수 STABILITY_KEY. 페이지에서 프롬프트 입력 → 이미지 표시." 생성에 5~15초 걸리니 로딩 표시 권장.

### 슬라이드 8 — 실습 3: 본인 사이트에 AI 기능 1개 추가

- **유형**: 실습
- **goal**: 자기 사이트 주제에 어울리는 AI 기능 한 가지를 학생 스스로 정의하고 Vercel 함수로 붙인다
- **핵심 토픽**:
  - 주제별 예시
    - 카페 사이트 → 오늘의 추천 메뉴 자동 생성
    - 포트폴리오 → 자기소개 문구 자동 작성
    - 여행 블로그 → 일정 3줄 요약
  - 절차: ① 기능 한 줄 정의 → ② 환경변수 확인 → ③ Claude Code 프롬프트 작성 → ④ 배포·확인
  - 막혔을 때: 에러 메시지를 그대로 Claude Code에 붙여넣기
- **시각 요소**:
  - 3컬럼 영감 카드 (카페 / 포트폴리오 / 여행)
  - 빈칸 채우기 프롬프트 템플릿 박스
  - 체크리스트: 정의 / 키 / 함수 / 페이지 / 배포 확인
- **강사 노트**: 프롬프트 — "내 사이트 주제는 [___]. 이 주제에 어울리는 AI 기능 1개를 Vercel 함수로 추가해줘." 결과보다 "내가 정의해서 붙였다"는 경험 자체가 목표.
