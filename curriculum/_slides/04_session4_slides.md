# Session 4 — JS 인터랙션 기초 / 슬라이드 목차

> **회차 한 줄 요약**: 정적인 사진 같던 페이지에 click·scroll·mousemove 3대 트리거를 붙여 "반응하는" 페이지로 진화시킨다.
> **총 슬라이드**: 8장 (표지 1 + 학습목표 1 + 개념 3 + 실습 3 + 정리 1 = 9... 이번 회차는 개념 2 + 실습 3으로 8장 유지)
> **대상**: 코딩 zero · Claude Code 능숙 · 위협감 X

### 슬라이드 1 — 오늘의 목표 (4회차 표지)

- **유형**: 표지
- **goal**: 4회차의 미션 — 멈춰 있던 페이지가 "반응하기" 시작하는 순간을 만난다.
- **핵심 토픽**:
  - 회차 타이틀: "JS 인터랙션 기초 — 페이지가 살아나는 순간"
  - 1개념 한 줄: **행동 = JS (3대 트리거)**
  - 오늘 끝나면 만들 수 있는 것: 클릭하면 메시지 뜨고 / 스크롤하면 등장하고 / 마우스 따라다니는 페이지
  - 소요: 2시간 · 트랙: Basic / Part 1
- **시각 요소**:
  - 좌측: 멈춰 있는 정적 페이지 일러스트
  - 우측: 반응하는 페이지 일러스트 (클릭·스크롤·마우스 아이콘 3개)
  - 가운데 화살표 "JS 추가 →"
- **강사 노트**: "지금까지 만든 페이지는 '사진'이었어요. 오늘부터는 '터치하면 반응하는 화면'으로 바뀝니다." 위협감 zero — Claude Code가 코드 다 써준다는 점 강조.

- **유형**: 학습목표

  - 5) **누적 위치**: 2~3주에 만든 정적 페이지가 오늘부로 "동적 페이지"로 한 단계 진화
- **시각 요소**:
  - 체크리스트 카드 4개 (개념 / 트리거 / 실습 / 재현)
  - 진행률 바: Step 4 / 전체 회차
- **강사 노트**: "오늘 끝나면 친구한테 '내 사이트 스크롤해봐' 자랑할 수 있게 됩니다." 목표는 '암기'가 아니라 '경험'.

### 슬라이드 3 — JS의 역할: 사진에서 엘리베이터로

- **유형**: 개념
- **goal**: HTML·CSS·JS의 역할 분담을 비유로 직관 이해한다.
- **핵심 토픽**:
  - **HTML** = 건물의 뼈대 (벽·문·창문)
  - **CSS** = 인테리어 (색·폰트·배치)
  - **JS** = 행동·기계장치 (엘리베이터·자동문·조명 스위치)
  - 비유 정리: HTML+CSS만 있으면 "사진 속 건물" / JS가 추가되면 "사람이 들어가서 작동하는 건물"
  - 우리가 지난 3주간 만든 것 = 사진 · 오늘부터 = 작동하는 건물
- **시각 요소**:
  - 좌: 사진 액자 안의 건물 그림 (HTML+CSS)
  - 우: 같은 건물인데 엘리베이터·문·조명이 움직이는 GIF 느낌의 일러스트 (HTML+CSS+JS)
  - 아래 표: 역할 | 비유 | 예시
- **강사 노트**: "JS가 어렵다는 인식 부수기. 우리는 '버튼 눌렀을 때 뭐 해줘'만 Claude Code에 말하면 됩니다." 절대 문법 외울 필요 없다 강조.

### 슬라이드 4 — 3대 트리거: click · scroll · mousemove

- **유형**: 개념
- **goal**: 웹 인터랙션의 90%를 차지하는 3대 사용자 행동(트리거)을 사례와 함께 익힌다.
- **핵심 토픽**:
  - **click**: 사용자가 무언가를 누르는 순간 → 버튼·메뉴·이미지 클릭
  - **scroll**: 사용자가 화면을 위/아래로 움직이는 순간 → 섹션 등장·패럴랙스·진행률 바
  - **mousemove**: 사용자가 마우스를 움직이는 순간 → 자기(磁氣) 효과·빛 따라오기·커스텀 커서
  - 공통 패턴: **"트리거가 발생하면 → 무슨 행동을 한다"** (이것만 알면 끝)
  - 실제 사이트 사례: Apple(스크롤 등장), Stripe(마우스 그라데이션), Linear(클릭 토글)
- **시각 요소**:
  - 3분할 카드: 각 트리거별 아이콘 + 사례 사이트 캡처 1장씩
  - 하단: "트리거 → 행동" 화살표 도식
- **강사 노트**: "트리거 3개만 알면 인터랙티브 웹의 90%는 설명 가능합니다." 학생들에게 "오늘 본 사이트 중 어떤 트리거 썼는지" 30초 회상 시간.

### 슬라이드 5 — 실습 1: 클릭 토글 (연락하기 버튼)

- **유형**: 실습
- **goal**: 가장 기본 트리거인 click을 내 페이지의 버튼에 붙여 메시지를 띄운다.
- **핵심 토픽**:
  - **목표 결과물**: "연락하기" 버튼 클릭 → "감사합니다! 곧 연락드리겠습니다." 메시지 등장
  - **개념 1줄**: `addEventListener('click', ...)` = "이 버튼을 클릭하면 이 행동을 해줘"
  - **활용 패턴**: class 토글 / 메시지 표시 / 색 변경 / 모달 열기
  - **Claude Code 프롬프트**: "연락하기 버튼을 클릭하면 '감사합니다! 곧 연락드리겠습니다.' 메시지가 나타나는 JS를 추가해줘."
  - **확장 미션**: 한 번 더 누르면 메시지 숨기기 (토글) / 색상도 함께 변경
- **시각 요소**:
  - Before/After 스크린샷: 클릭 전 vs 클릭 후
  - 코드박스 (3~5줄): button.addEventListener('click', () => { ... })
  - Claude Code 프롬프트 박스 (복붙용)
- **강사 노트**: 첫 실습은 무조건 "성공 경험". 학생이 직접 클릭해서 메시지 뜨는 순간 박수. 코드는 Claude가 쓰지만 "어디에 붙는지"는 같이 본다.

### 슬라이드 6 — 스크롤 등장의 원리: IntersectionObserver

- **유형**: 개념
- **goal**: 스크롤 등장 효과의 작동 원리를 한 단어로 이해한다 — "이 요소가 화면에 들어왔는지" 감지.
- **핵심 토픽**:
  - **문제 상황**: 모든 섹션이 처음부터 다 보이면 지루함
  - **해결책**: 화면에 보일 때만 등장 (페이드인 + 아래에서 위로)
  - **핵심 도구**: `IntersectionObserver` = "이 요소가 화면(viewport)에 들어왔는지 자동 감지해주는 망원경"
  - 옛날 방식(scroll 이벤트 + 좌표 계산) vs 지금 방식(IntersectionObserver) — 후자가 훨씬 부드럽고 가벼움
  - 트리거: scroll · 행동: opacity 0→1 + translateY 20px→0
- **시각 요소**:
  - 다이어그램: 뷰포트(브라우저 창) + 섹션 박스가 위에서 아래로 들어오는 애니메이션 시퀀스
  - "감지!" 라벨이 박스에 닿는 순간 표시
  - 코드 한 줄 미리보기 (개념용)
- **강사 노트**: "IntersectionObserver"라는 단어 외울 필요 X. "스크롤 등장 = 화면 감지" 키워드만 기억. Claude Code에게 "IntersectionObserver로 페이드인" 한 마디면 끝.

### 슬라이드 7 — 실습 2 & 3: 스크롤 등장 + 마우스 따라가기

- **유형**: 실습
- **goal**: 남은 2개 트리거(scroll, mousemove)를 한 번에 붙여 페이지를 완성한다.
- **핵심 토픽**:
  - **실습 2 — 스크롤 등장**:
    - 결과: 각 섹션이 스크롤로 보일 때 아래에서 위로 페이드인
    - 프롬프트: "각 섹션이 스크롤로 화면에 보일 때 아래에서 위로 페이드인 되도록 IntersectionObserver로 구현해줘."
  - **실습 3 — 마우스 따라가기**:
    - 결과: 히어로 섹션 위에서 동그란 커서가 마우스를 부드럽게 따라옴
    - 핵심 개념: `e.clientX`, `e.clientY` = 마우스의 현재 좌표 / `transform: translate`로 위치 이동
    - 프롬프트: "히어로 섹션 위에 마우스 따라다니는 동그란 커서 효과를 추가해줘."
  - **공통 팁**: 안 되면 "콘솔에 에러 뜨는지 확인하고 고쳐줘"라고 Claude에 한 줄 더
- **시각 요소**:
  - 2분할 레이아웃: 좌 스크롤 등장 GIF / 우 마우스 추적 GIF
  - 각각 Claude Code 프롬프트 박스 (복붙용)
  - 하단 체크포인트: [ ] 스크롤 등장 작동 [ ] 마우스 커서 작동 [ ] Vercel에 재배포
- **강사 노트**: 시간 부족하면 마우스 따라가기는 "도전 미션"으로 남기기. 둘 다 성공한 학생은 "색상 바뀌게" 같은 변주 시도 권장. 끝나면 Vercel로 진짜 사이트에 재배포까지.

### 슬라이드 8 — 핵심 정리 & 다음 주 예고

- **유형**: 정리
- **goal**: 오늘 배운 "트리거 → 행동" 패턴을 한 장으로 압축하고 다음 회차를 예고한다.
- **핵심 토픽**:
  - **오늘의 1줄 정리**: 인터랙션 = **트리거(click·scroll·mousemove) → 행동(class·스타일·위치 변경)**
  - **3대 트리거 한 표 요약**:
    - click → 버튼·메뉴 → addEventListener('click')
    - scroll → 섹션 등장 → IntersectionObserver
    - mousemove → 커서·자기 효과 → e.clientX/Y + transform
  - **누적 성장**: 1주(구조) → 2주(스타일) → 3주(레이아웃) → **4주(인터랙션 완성)**
  - **체크리스트**: 클릭 토글 / 스크롤 등장 / 마우스 추적 — 모두 내 페이지에서 작동?
  - **다음 주 예고 (Session 5)**: GSAP — "JS로 한 줄씩 쓰던 애니메이션을 영화 장면처럼 만드는 라이브러리"
- **시각 요소**:
  - 상단: 트리거-행동 매트릭스 표
  - 중단: 4주차까지의 성장 타임라인 (게이지 4/N 채워짐)
  - 하단: 다음 주 GSAP 티저 이미지 (한 줄 코드로 부드러운 모션)
- **강사 노트**: "오늘부터 여러분 페이지는 '살아 있는' 페이지입니다." Vercel에 올린 본인 사이트 링크 단톡방에 공유 미션 부여. 다음 주 GSAP은 "오늘 한 인터랙션이 영화처럼 부드러워지는 회차"로 기대감 조성.
