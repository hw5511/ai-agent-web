# Session 1 슬라이드 목차 — AI로 웹 만드는 세계 (청사진)

> **회차 정보**: Basic / Part 1 / 2시간
> **1개념**: AI 시대 웹 만들기란 무엇인가
> **총 슬라이드**: 10장 (특수 구조 — 1회차는 청사진 + Hello World 셋업 포함)
> **누적 위치**: 16주 코스의 출발점. 학생 정체성("AI를 잘 부리는 사람") 정립 회차

---

### 슬라이드 1 — 환영합니다, 16주의 시작
- **유형**: 표지
- **goal**: 16주 코스 1회차 시작을 환영하고 오늘 2시간이 어디로 데려갈지 그림을 보여준다
- **핵심 토픽**:
  - "AI로 웹 만드는 세계 — 청사진" (회차 제목)
  - 1회차 / 전체 16회차 / 2시간
  - "오늘은 만들고, 보고, 깨닫고, 다시 시작합니다"
  - 1개념: **AI 시대 웹 만들기란 무엇인가**
- **시각 요소**: 16주 로드맵 미니맵 (1주차 위치 강조), 16개 마디로 된 진행 바
- **강사 노트**: 환영 인사 후 "오늘 2시간이 16주 전체의 방향을 결정합니다" — 무게감 살짝만 주고 분위기는 가볍게.

---

### 슬라이드 2 — 오늘의 학습 목표
- **유형**: 학습목표
- **goal**: 2시간 끝에 학생이 손에 쥘 3가지 결과물을 명확히 보여준다
- **핵심 토픽**:
  - 결과물 1: 내가 만든 Claude Design 페이지 1개
  - 결과물 2: 16주 후 내 모습의 청사진 (머릿속 지도)
  - 결과물 3: Claude Code로 띄운 첫 "안녕하세요" 페이지
  - 오늘 끝나면: "나도 만들 수 있구나" + "근데 더 알고 싶다"
- **시각 요소**: 3개 결과물 카드(체크박스 형태), 좌→우 시간 흐름 표시
- **강사 노트**: "코딩 한 줄도 안 써봤어도 오늘 끝에는 본인 페이지가 손에 들려있을 거예요. 그게 시작이에요."

---

### 슬라이드 3 — 1시간 실습: Claude Design 안내
- **유형**: 실습
- **goal**: claude.ai/design에 접속해 본인 주제로 1시간 동안 페이지를 자유롭게 만들어본다
- **핵심 토픽**:
  - claude.ai/design 접속 (Pro 구독 확인)
  - 본인 주제 1개 정하기 — 포트폴리오 / 카페 / 취미 블로그 / 사이드 프로젝트
  - 자유롭게 프롬프트 던지기 — "만들어줘", "바꿔줘", "더 예쁘게"
  - 1시간 끝에 결과물 핸드오프 받기 (tar.gz 다운로드)
- **시각 요소**: claude.ai/design 화면 스크린샷, 주제 예시 4개 카드(아이콘 포함), tar.gz 다운로드 버튼 위치 표시
- **강사 노트**: "잘 만들려고 애쓰지 마세요. 그냥 던지고 받고 던지고 받고. 1시간이 어떻게 갔는지 모를 거예요." 강사는 한 명씩 돌면서 막힌 부분만 풀어줌.

### 슬라이드 4 — 방금 만든 그것은 "랜딩페이지"
- **유형**: 개념
- **goal**: 1시간 실습 결과물이 웹의 1가지 형태인 "랜딩페이지"임을 인식한다
- **핵심 토픽**:
  - 랜딩페이지 = 1페이지 스크롤형, "보여주기 위한 페이지"
  - 특징: 정보 전달이 목적 / 누르는 기능은 거의 없음 / 예쁘게가 핵심
  - Wix · Webflow · Framer 같은 도구로도 만드는 것 — 이제 Claude Design도 합류
  - "방금 만든 게 이거예요" — 본인 결과물 다시 보기
- **시각 요소**: 랜딩페이지 예시 3개 썸네일(Apple, Linear, Stripe 같은 유명 사례), Claude Design 결과물도 같은 카테고리에 분류된 다이어그램
- **강사 노트**: "방금 만든 거, 사실 웹의 한 종류예요. 다른 종류도 많아요. 다음 슬라이드에서 보여드릴게요."

### 슬라이드 5 — 웹의 4갈래
- **유형**: 개념
- **goal**: 웹사이트가 랜딩·SaaS·쇼핑몰·사내도구 4갈래로 나뉜다는 큰 지도를 본다
- **핵심 토픽**:
  - 랜딩페이지 — 보여주는 사이트 (이번 수업 메인)
  - SaaS — Notion · Slack · Figma 같은 "기능이 도는" 서비스
  - 쇼핑몰 — 자사몰 · 스토어 (상품·결제·주문)
  - 사내도구 — 회사 안에서만 쓰는 내부 시스템
  - 16주 동안 우리는 1번 → 점점 2·3·4번 영역도 건드림
- **시각 요소**: 4분할 격자 다이어그램, 각 칸마다 대표 사이트 사진 3개씩(랜딩 예시·Notion·자사몰·관리자 대시보드)
- **강사 노트**: "각 갈래마다 만드는 방식이 다 달라요. 이 수업은 1번에서 시작해서 점점 다른 갈래도 만질 수 있게 됩니다."

### 슬라이드 6 — 16주 청사진: Part 1 + Part 2
- **유형**: 개념
- **goal**: 기초 8주(랜딩+진짜 사이트로 배포) → 심화 8주(데이터+도메인+회원+결제) 흐름을 머릿속에 그린다
- **핵심 토픽**:
  - **Part 1 (1~8주)**: HTML/CSS/JS 뼈대 → React 컴포넌트 → DESIGN.md → 진짜 사이트로 배포
  - **Part 2 (9~16주)**: Vercel을 활용한 DB·API 연동 → 회원 시스템 → 본인 도메인 → 결제 흐름
  - 8주차 마일스톤: 본인이 통제하는 랜딩이 인터넷에 떠 있음
  - 16주차 마일스톤: 본인 도메인에 결제 도는 사이트 보유
  - 매주 1개념씩만 — 누적식 구조
- **시각 요소**: 16칸 타임라인(Part 1·Part 2 색깔 구분), 8주차·16주차 마일스톤에 깃발 아이콘, 매주 1개념 라벨
- **강사 노트**: "지금은 멀게 느껴져도 매주 하나씩만 쌓으면 16주 후엔 진짜 본인 사이트가 도메인에 떠 있을 거예요."

### 슬라이드 7 — 메타 키워드: HTML · React · DESIGN.md
- **유형**: 개념
- **goal**: 앞으로 자주 들을 3가지 핵심 키워드의 정체를 미리 한 번 인식한다
- **핵심 토픽**:
  - **HTML/CSS/JS** — 웹의 3대 뼈대 (HTML=구조, CSS=스타일, JS=움직임)
  - **React + 컴포넌트** — 요즘 UXUI 디자이너가 일하는 방식 (조각 모아 화면 만들기)
  - **DESIGN.md** — Google이 만든 AI 시대 디자인 표준 문서 (Claude에게 디자인 룰 전달용)
  - 오늘은 "이런 게 있구나"만, 자세한 건 매주 풀어감
- **시각 요소**: 3단 카드 레이아웃 (HTML/React/DESIGN.md), 각 카드 하단에 "N주차에서 만남" 미리 표시
- **강사 노트**: "지금 다 이해 안 돼도 됩니다. 이름만 귀에 들어왔으면 성공이에요. 다음 주부터 하나씩 풀어갑니다."

### 슬라이드 8 — AI 시대 웹디자이너의 정체성
- **유형**: 개념
- **goal**: "Claude Design이 잘 만들어주는데 왜 더 배워?"라는 질문에 답을 가지고 간다
- **핵심 토픽**:
  - 질문: "방금 Claude Design이 다 만들어줬는데 16주를 왜?"
  - 답 1: 결과물을 진짜 내 것으로 통제하려면 코드 구조를 알아야 함
  - 답 2: AI가 만든 걸 "이거 왜 이렇게 했지"라고 읽을 수 있어야 함
  - 답 3: 진짜 사이트로 배포·운영하려면 AI 너머의 영역이 필요함
  - 우리의 정체성: **AI를 부리는 사람** (휘둘리는 사람 X)
- **시각 요소**: 좌측 "AI만 쓰는 사람" vs 우측 "AI 부리는 사람" 대비 일러스트, 가운데 화살표 "16주의 차이"
- **강사 노트**: "이 회차의 가장 중요한 메시지예요. 지금 이거 못해도 당연한 거고, 16주가 그 통제력을 만들어주는 시간이에요."

---

### 슬라이드 9 — 첫 실습: Claude Code로 Hello World
- **유형**: 실습
- **goal**: Claude Code 환경에서 "안녕하세요 [본인 이름]" 페이지를 띄워본다
- **핵심 토픽**:
  - Claude Code 환경 열기 (이미 익숙한 도구)
  - 프롬프트: "안녕하세요 [본인 이름]이 적힌 HTML 페이지를 만들어줘"
  - 만들어진 .html 파일 브라우저로 열어보기
  - "이게 진짜 코드로 만든 첫 페이지" — Claude Design과 차이 느끼기
- **시각 요소**: Claude Code 화면 + 결과 HTML 페이지 좌우 분할 스크린샷, 화살표로 "프롬프트 → 코드 → 페이지" 흐름
- **강사 노트**: "Claude Design은 결과만 줬다면, Claude Code는 코드를 보여줘요. 다음 주부터 이 코드를 우리가 읽고 통제합니다." 환경 안 되는 학생 1:1 도움.

### 슬라이드 10 — 핵심 정리 & 다음 주 예고
- **유형**: 정리
- **goal**: 오늘 3가지 핵심을 다시 짚고 2주차로 가는 다리를 놓는다
- **핵심 토픽**:
  - 핵심 1: 랜딩페이지는 누구나 만들 수 있다 (직접 증명함)
  - 핵심 2: 웹은 4갈래, 16주에 걸쳐 점점 넓혀감
  - 핵심 3: 우리 정체성은 "AI를 부리는 사람" — 코드를 읽고 통제하는 사람
  - 다음 주(2회차): **HTML 뼈대** — Claude Design이 만든 코드 안에 뭐가 들었는지 열어봄
  - 숙제 없음, 오늘 만든 페이지만 잘 간직
- **시각 요소**: 3개 핵심 체크리스트, 하단 2주차 티저 카드(HTML 태그 아이콘), 16주 진행 바에서 1주차 완료 체크
- **강사 노트**: "오늘 페이지 만든 거, 자랑하고 싶으면 자랑하세요. 그게 첫 결과물이에요. 다음 주에 그 안을 열어봅시다."

## 회차 특이사항 메모

- **특수 구조 회차**: 1·8·16회차는 표준 8장보다 길다. 이번 1회차는 청사진 + Hello World 셋업까지 포함해 **10장**.
- **시간 배분 특수**: 0:00~1:00 실습 → 1:00~1:40 강의 → 1:40~2:00 실습. 보통 회차와 순서가 거꾸로 (실습 → 이론 → 실습).
- **표현 가이드 준수**: "백엔드"·"풀스택"·"서버 사이드"·"API 서버"·"프로덕션" 단어 0회 등장. 슬라이드 6에서 "Vercel을 활용한 DB·API 연동", "회원 시스템", "진짜 사이트로 배포" 표현 사용.
- **분위기**: 위협감 X. "이거 못해도 당연"을 슬라이드 8·9 강사 노트에 명시.
