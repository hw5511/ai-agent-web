### 슬라이드 3 — 개념 ①: 마우스 트리거 3종 비교
- **유형**: 개념
- **goal**: hover / click / mousemove 세 트리거의 차이와 용도를 구분한다.
- **핵심 토픽**:
  - **hover**: 마우스가 요소 위로 올라갔을 때 (색 변화, 확대)
  - **click**: 한 번 눌렀을 때 (펼침, 토글)
  - **mousemove**: 커서가 움직이는 매 순간 (자석, 빛 추적)
  - 판단 기준: "상태가 2개면 hover/click, 좌표가 필요하면 mousemove"
- **강사 노트**: 오늘 만들 3개 실습이 각각 어느 트리거에 속하는지 미리 짚어주기 (마그네틱·spotlight = mousemove, flip = hover).

### 슬라이드 4 — 개념 ②: 좌표 추적의 원리 (CEO 2026-05-26 쉬운 모델로 재구성)
- **유형**: 개념
- **goal**: 마우스 위치를 숫자로 읽어 그 숫자로 값을 바꾸는 것이 좌표 추적임을 쉽게 이해한다.
- **핵심 토픽**:
  - STEP 1 마우스 감지: 커서가 지금 어디 있는지 계속 지켜본다
  - STEP 2 숫자로 읽기: 마우스 위치 = 가로 X, 세로 Y 두 숫자
  - STEP 3 값에 연결: 그 숫자로 위치·크기·밝기를 바꾼다
  - 스크롤(5주차)과 똑같다 — 이번엔 '스크롤 숫자' 대신 '마우스 숫자'를 연결
- **시각 요소**: 3컷 흐름(감지 → 숫자 → 값에 연결) + 연결 한 줄(스크롤과 동일) + 그린 핵심("마우스 위치(숫자)를 어떤 값에든 연결한다 — 그게 전부")
- **참고**: 옛 'CSS vs JS 제어' 슬라이드는 폐지(CEO 2026-05-26) — 분업 내용은 실습에서 자연스럽게 체득.
- **강사 노트**: 수학·용어 공포감 차단. clientX/getBoundingClientRect/피타고라스 같은 용어 대신 "위치를 숫자로 읽어, 그 숫자를 값에 연결"이라는 한 모델로. 5주차 스크롤 원리와 같은 사고틀임을 강조.

### 슬라이드 5 — 실습 ①: 마그네틱 버튼 (mousemove + transform)
- **유형**: 실습
- **goal**: 마우스가 가까이 오면 살짝 당겨지는 "연락하기" 버튼을 만든다.
- **핵심 토픽**:
  - 단계: 대상(연락하기 CTA) → 발동 반경(예 150px) → 끌림 강도(0.3) → 멀어지면 복귀 → 숫자 바꿔보며 조절
  - 동작: 일정 거리 이내에서 버튼이 마우스 방향으로 살짝 이동
- **프롬프트 예시(슬라이드 내 박스)**: "연락하기 버튼에 마그네틱 효과 추가해줘. 마우스가 근처 오면 버튼이 마우스 방향으로 살짝 당겨지게."
- **시각 요소**: 좌 단계 글머리 + 좌하단 프롬프트 예시 박스(#f9fafb) / 우 Before·After + 동작 흐름(마우스 좌표→거리 측정→버튼 이동) + 그린 핵심("강도 0.3이 가장 자연스럽다")
- **강사 노트**: 끌림 강도 0.3 정도가 자연스러움. 너무 강하면 어색함 — 학생이 직접 숫자 바꿔보게 유도.

---

### 슬라이드 6 — 실습 ②: Flip Card (CSS rotateY + perspective)
- **유형**: 실습
- **goal**: 작품 카드를 hover하면 3D로 뒤집혀 설명이 나오는 카드로 만든다.
- **핵심 토픽**:
  - 단계: 대상(작품 카드) → 앞/뒷면 콘텐츠 나누기 → perspective 입체감 → hover에 rotateY 180° → backface-visibility로 뒷면 가리기
  - 앞면: 이미지 + 제목 / 뒷면: 한 줄 설명 + 링크
  - 트리거: hover (JS 거의 불필요 → CSS 단독 패턴 사례)
- **프롬프트 예시(슬라이드 내 박스)**: "작품 카드를 Flip Card로 만들어줘. 앞면 이미지+제목, 뒷면 설명. hover로 뒤집기."
- **시각 요소**: 좌 단계 글머리 + 좌하단 프롬프트 예시 박스(#f9fafb) / 우 3D 뒤집기 시퀀스(0°→90°→180°) + 핵심 속성 + 그린 핵심("JS 없이 CSS만으로 — 상태 2개짜리 인터랙션의 정석")
- **강사 노트**: perspective 값(1000px 정도)이 자연스러운 입체감 핵심. perspective를 0으로 줘보고 차이 체험하게 하면 좋음.

---

### 슬라이드 7 — 실습 ③: Spotlight Follow (radial-gradient 좌표 추적)
- **유형**: 실습
- **goal**: 다크 히어로 섹션에서 커서 주변만 환해지는 빛 효과를 만든다.
- **핵심 토픽**:
  - 단계: 대상(히어로) → 배경 어둡게 → radial-gradient로 빛의 원 → mousemove로 중심 좌표 갱신 → 반경·밝기로 분위기 조절
  - 동작: mousemove마다 빛의 중심 좌표를 커서로 갱신
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 섹션에 마우스 따라다니는 빛 효과 추가해줘. 다크 배경에서 커서 주변만 밝아지도록."
- **시각 요소**: 좌 단계 글머리 + 좌하단 프롬프트 예시 박스(#f9fafb) / 우 빛 동심원 시연 + 핵심 속성 + 그린 핵심("이거 하나로 사이트가 영화처럼 보인다")
- **강사 노트**: 빛 반경(예 300px)과 밝기 차이로 분위기가 확 달라짐. "이거 하나로 사이트가 영화처럼 보여요" — wow 모먼트 마무리.

### 슬라이드 8 — 핵심 정리 & 다음 회차 예고
- **유형**: 정리
- **goal**: 좌표 추적 패턴을 정리하고 다음 주(라이브러리) 학습으로 연결한다.
- **핵심 토픽**:
  - 오늘 배운 패턴: hover 전환 / mousemove 좌표 / 마우스 숫자를 값에 연결
  - 자산 점검: 마그네틱 버튼 · Flip Card · Spotlight = 포트폴리오에 실제 적용 완료
  - 누적 인터랙션 지도: 스크롤(5주) + 마우스(6주) = 트리거 양대 축 완성
  - 다음 주 예고: "직접 짜지 않고 라이브러리로 더 화려한 인터랙션 가져오기"
