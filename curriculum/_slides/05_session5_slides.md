# Session 5 — 스크롤 라이브러리 (GSAP) 슬라이드 목차

> **회차 정보**: Basic / Part 1 · 2시간 · 1개념(GSAP ScrollTrigger)
> **회차 끝 학생 상태**: 시네마틱한 스크롤 페이지 (페이드인 / 수평 스크롤 / 텍스트 컬러 reveal / 패럴랙스 4종 완성)
> **변경(CEO 2026-05-26)**: 3페이지 다음 'GSAP란?' 개념 1장 추가, 수평 스크롤·컬러 reveal 원리를 "스크롤 위치를 숫자로 읽어 → 어떤 값에든 연결"이라는 쉬운 모델로 재구성, 실습 1·2·3에 프롬프트 예시 박스 추가, 합본이던 실습3+정리를 분리하고 GSAP 추가 실습(패럴랙스)을 더해 정리를 마지막으로 (8→11장).
> **타깃**: 코딩 zero · Claude Code 능숙 · 위협감 X

### 슬라이드 1 — 오늘은 "영화 같은 스크롤"을 만듭니다
- **유형**: 표지
- **goal**: 5회차에서 GSAP ScrollTrigger로 시네마틱 스크롤 페이지를 완성한다는 기대감을 심는다.
- **핵심 토픽**:
  - 회차 타이틀: "스크롤 라이브러리 — GSAP ScrollTrigger"
  - 4주차(직접 만든 단순 JS 스크롤) → 5주차(라이브러리 풀 활용)로 점프
  - 오늘 결과물 미리보기: 페이드인 / 수평 스크롤 / 텍스트 컬러 reveal / 패럴랙스
  - 한 줄 약속: "코드 한 줄도 직접 안 써도, 진짜 사이트 같은 움직임이 나온다"
- **강사 노트**: 영화관 화면 같은 느낌을 강조하며 시작. "오늘 만든 페이지는 친구에게 보여줘도 '이거 진짜야?' 소리 들을 거예요"로 자신감 부여.

### 슬라이드 2 — 오늘의 학습 목표
- **유형**: 학습목표
- **goal**: 2시간 안에 GSAP ScrollTrigger 효과들을 적용해 시네마틱 페이지를 완성한다.
- **핵심 토픽**:
  - 목표 1: GSAP가 "남이 만들어 놓은 기능 묶음(라이브러리)"임을 이해한다
  - 목표 2: 페이드인 — 섹션이 화면에 들어오면 자동으로 떠오르게 한다
  - 목표 3: 수평 스크롤 — 세로 휠을 가로 움직임으로 바꾸는 갤러리 만들기
  - 목표 4: 텍스트 컬러 reveal — 스크롤 진행률에 따라 글자가 회색→검정으로 밝아짐
  - 목표 5: 패럴랙스 — 배경이 본문보다 천천히 흘러 깊이감을 더한다
  - 도착점: 4주차 페이지에 4가지 효과가 모두 얹어진 시네마틱 버전
- **강사 노트**: 학생들에게 "오늘은 코드를 외울 필요 없고, 효과 '이름'만 기억하면 됨"이라고 안심시킨다.

### 슬라이드 3 — 라이브러리란? (script 한 줄로 수천 줄을 빌려쓰기)
- **유형**: 개념
- **goal**: CDN 라이브러리 개념을 "이미 만들어진 기능 묶음 빌려오기"로 직관 이해한다.
- **핵심 토픽**:
  - 라이브러리 = 누군가가 미리 만들어 둔 기능 세트
  - HTML `<script src="...">` 한 줄 = 수천 줄 코드 통째로 가져오기
  - CDN: 전 세계 어디서나 빠르게 받아오는 "공용 창고"
  - 우리는 코드 안 짜고 "이름만" 알면 된다 → 나머지는 Claude Code가 사용법 적용
  - 오늘 빌릴 도구: GSAP + GSAP ScrollTrigger
- **강사 노트**: 학생이 자주 묻는 "이거 다운로드해야 해요?"는 NO. 그냥 script 태그만 붙이면 끝이라고 강조.

### 슬라이드 4 — GSAP란? (CEO 2026-05-26 신설)
- **유형**: 개념
- **goal**: GSAP가 무엇이고 ScrollTrigger가 스크롤에 애니메이션을 연결하는 추가 기능임을 안다.
- **핵심 토픽**:
  - GSAP = GreenSock Animation Platform, 움직임(애니메이션)을 만들어 주는 JS 도구
  - 부드럽고 정교한 움직임을 짧은 코드로, 브라우저 차이도 알아서 처리
  - ScrollTrigger = 스크롤에 애니메이션을 '연결'하는 GSAP 추가 기능
  - 전 세계 수많은 시네마틱 사이트가 사용 · 무료, CDN 한두 줄로 가져와 바로 사용
  - GSAP가 잘하는 것: 페이드인 / 가로·세로 이동 / 색·크기 변화 / 스크롤 연동
- **시각 요소**: 좌 글머리 5개 + 우 'GSAP가 잘하는 것' 카드 + 그린 핵심 한 줄("복잡한 움직임을, 짧은 한 줄로 — 그게 GSAP")
- **강사 노트**: "이름만 알면 됩니다. GSAP라는 도구가 있고, ScrollTrigger로 스크롤에 연결한다 — 딱 이 두 단어." 간결 조사 기반.

### 슬라이드 5 — 수평 스크롤의 원리 (CEO 2026-05-26 쉬운 모델로 재구성)
- **유형**: 개념
- **goal**: 스크롤 위치를 숫자(0~1)로 읽어 가로 이동에 연결하는 것이 수평 스크롤임을 이해한다.
- **핵심 토픽**:
  - STEP 1 스크롤 감지: 지금 어디까지 왔는지 계속 지켜본다
  - STEP 2 숫자로 읽기: 스크롤 위치 = 0에서 1 사이 진행률 숫자 하나
  - STEP 3 가로로 이동: 그 숫자만큼 카드를 옆으로 민다
  - 세로로 굴린 휠이 → 가로 흐름처럼 보인다
- **시각 요소**: 3컷 흐름(감지 → 숫자 → 가로 이동) + 입력/출력 한 줄 + 그린 핵심("스크롤 위치(숫자)를 '가로 위치'에 연결한 것 — 그게 전부")
- **강사 노트**: pin/translateX 같은 용어 대신 "스크롤 위치를 숫자로 읽어, 그 숫자를 가로 위치에 연결"이라는 한 모델로 설명. 다음 reveal 슬라이드와 동일한 사고틀.

### 슬라이드 6 — 텍스트 컬러 reveal의 원리 (CEO 2026-05-26 동일 모델로 재구성)
- **유형**: 개념
- **goal**: 같은 스크롤 숫자를 이번엔 글자 색에 연결해 회색에서 검정으로 또렷해지는 reveal을 이해한다.
- **핵심 토픽**:
  - 스크롤 위치를 숫자 0~1로 읽는다 (수평 스크롤과 동일)
  - 그 숫자를 이번엔 '글자 색'에 연결한다
  - 숫자 0 = 연한 회색 / 0.5 = 중간 회색 / 1 = 검정으로 또렷이
  - 수평 스크롤과 똑같은 원리 — 연결하는 대상만 '위치'에서 '색'으로 바뀐 것
- **시각 요소**: 진행률 슬라이더(0/0.5/1) + 숫자별 Headline 색 비교 3컷 + 그린 핵심("스크롤 숫자에 '색'을 연결 — 수평 스크롤과 똑같은 원리")
- **강사 노트**: "어렵게 보이지만 5페이지랑 완전히 같은 얘기예요. 스크롤 숫자를 어디에 연결하느냐만 달라요." 색 말고 크기·위치도 가능함을 질문으로 유도.

### 슬라이드 7 — 실습 ①: 섹션 페이드인 (가장 쉬운 1줄 효과)
- **유형**: 실습
- **goal**: 4주차 페이지의 모든 섹션에 GSAP 페이드인 효과를 1번의 프롬프트로 추가한다.
- **핵심 토픽**:
  - 단계: 4주차 페이지 열기 → GSAP CDN 두 줄 확인 → 프롬프트 복붙·새로고침 → 빠르면 "좀 더 천천히"
  - 효과: 섹션이 화면에 들어올 때 아래에서 위로 떠오르며 등장
  - 4주차 페이지를 그대로 베이스로 사용 (재활용)
- **프롬프트 예시(슬라이드 내 박스)**: "페이지 각 섹션에 GSAP ScrollTrigger로 페이드인 효과 추가해줘. 아래에서 위로."
- **시각 요소**: 좌 단계 글머리 4개 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("코드는 Claude가, 의도는 내가")
- **강사 노트**: 학생 90%가 "어 진짜 이게 다야?"라고 함. 프롬프트 한 줄로 끝나는 마법 같은 순간 강조.

### 슬라이드 8 — 실습 ②: 작품 갤러리 수평 스크롤
- **유형**: 실습
- **goal**: 작품 갤러리를 가로로 흐르는 카드 4장 레이아웃으로 바꾼다.
- **핵심 토픽**:
  - 단계: 갤러리 섹션 위치 알려주기 → 프롬프트 복붙·새로고침 → 멈추고 가로로 흐르는지 확인 → 안 흐르면 "카드를 화면 폭보다 넓게"
  - 효과: 갤러리 도착 → 섹션이 잠시 멈추고 카드 4장이 가로로 흘러감
  - 적용 위치: 4주차에 만든 작품 갤러리 섹션
- **프롬프트 예시(슬라이드 내 박스)**: "작품 갤러리에 카드 4개가 가로로 흐르는 수평 스크롤 효과를 GSAP로 만들어줘."
- **시각 요소**: 좌 단계 글머리 4개 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("'와!' 가 나오는 구간 — 굴려보는 시간 30초")
- **강사 노트**: 가장 "와!" 소리 나오는 구간. 학생들이 휠을 굴리며 신기해할 시간을 30초 이상 확보.

### 슬라이드 9 — 실습 ③: 헤드라인 컬러 reveal (CEO 2026-05-26 정리와 분리)
- **유형**: 실습
- **goal**: 히어로 헤드라인이 스크롤에 따라 회색에서 검정으로 밝아지는 컬러 reveal을 완성한다.
- **핵심 토픽**:
  - 단계: 헤드라인 위치 알려주기 → 프롬프트 복붙·새로고침 → 천천히 밝아지는지 확인 → 빠르면 "더 천천히 밝아지게"
  - 적용 위치: 4주차에 만든 히어로 섹션 메인 헤드라인
  - 원리: 스크롤 숫자에 색을 연결 (6페이지 원리 그대로)
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 헤드라인이 스크롤 진행률에 따라 회색에서 검정으로 밝아지는 reveal 효과 만들어줘."
- **시각 요소**: 좌 단계 글머리 4개 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("스크롤 숫자에 '색'을 연결 — 6페이지 원리 그대로")
- **강사 노트**: 5·6페이지에서 본 원리가 실제로 작동하는 순간. "원리 한 번, 효과 무한"을 다시 강조.

### 슬라이드 10 — 실습 ④: 패럴랙스 배경 (CEO 2026-05-26 GSAP 추가 실습)
- **유형**: 실습
- **goal**: 배경이 본문보다 천천히 움직이는 패럴랙스로 화면에 깊이감을 더한다.
- **핵심 토픽**:
  - 단계: 히어로(큰 섹션) 배경 위치 알려주기 → 프롬프트 복붙·새로고침 → 배경이 더 느리게 움직이는지 확인 → 약하면 "차이를 더 크게"
  - 효과: 스크롤할 때 배경이 본문보다 느리게 움직여 깊이감(레이어)이 생김
  - 원리: 스크롤 숫자를 '배경 이동 속도'에 연결한 것 — 오늘 배운 원리 그대로
- **프롬프트 예시(슬라이드 내 박스)**: "히어로 배경 이미지가 스크롤할 때 본문보다 느리게 움직이는 패럴랙스 효과를 GSAP로 추가해줘."
- **시각 요소**: 좌 단계 글머리 4개 / 우 프롬프트 예시 박스(#f9fafb) + 그린 핵심("배경과 본문의 속도 차이 = 깊이감")
- **강사 노트**: 4번째 효과로 "스크롤 숫자 → 어떤 값에든 연결" 사고가 한 번 더 반복되며 굳어짐. 패럴랙스는 가장 '고급스러워' 보이는 효과라 마무리 동기 부여에 좋음.

### 슬라이드 11 — 핵심 정리 & 다음 회차 예고 (CEO 2026-05-26 분리 신설)
- **유형**: 정리
- **goal**: 오늘 만든 GSAP 효과 4종과 하나의 원리를 정리하고 다음 회차를 예고한다.
- **핵심 토픽**:
  - 오늘 완성한 효과 4종: 페이드인 / 수평 스크롤 / 컬러 reveal / 패럴랙스
  - 기억할 원리: 스크롤 위치를 '숫자(0~1)'로 읽어 → 색·크기·위치 어디에든 연결한다
  - 우리는 '이름'만 안다 — 코드는 Claude Code가
  - 키워드: GSAP / ScrollTrigger / progress(스크롤 진행률)
  - 다음 회차(Session 6) 예고: 마우스 인터랙션 — 커서 따라가는 효과
- **시각 요소**: 효과 4종 카드 4장 + 기억할 원리 글머리 3개 + 그린 핵심("진행률 숫자 한 개에 효과 한 개 — 원리만 알면 응용은 무한") + 다음 회차 예고
- **강사 노트**: 마지막은 학생이 자기 페이지 스크롤하며 자랑하는 시간으로. "이제 진짜 사이트로 배포만 남았어요"로 다음 주 동기 부여.

## 부록: 자주 발생하는 문제 (강사 대응)

- **GSAP가 안 움직여요** → 1순위: CDN script 태그 2줄(core + ScrollTrigger)이 `<head>` 또는 `<body>` 끝에 있는지 확인
- **수평 스크롤 카드가 안 흘러요** → 갤러리 컨테이너 `width`가 화면 폭보다 커야 함 ("카드 4장이 화면 폭을 넘게 가로로 배치해줘" 추가 프롬프트)
- **텍스트 색이 한 번에 변해요** → 부드러운 연결 옵션 누락 가능성. "스크롤하면서 부드럽게 변하게 해줘" 후속 프롬프트
- **패럴랙스 효과가 약해요** → "배경과 본문의 속도 차이를 더 크게 해줘" 후속 프롬프트
- **페이드인이 너무 빨라요/느려요** → "페이드인 속도를 좀 더 천천히" 조정 요청
