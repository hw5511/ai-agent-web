# Session 2 — 색상과 폰트로 퀄리티가 달라진다

## 1. 회차 개요

- **시간**: 2시간
- **트랙**: Basic
- **목표**: 색상 팔레트와 Google Fonts 적용 원리를 이해하고 1회차 결과물을 리디자인한다.
- **핵심 topics**:
  - 색상 팔레트 선정 원칙
  - 웜/쿨/뉴트럴/다크 색상 유형
  - Google Fonts CDN 적용법
  - Serif/Sans-Serif/Display 폰트 분류
  - 1회차 랜딩페이지 before/after 비교
- **실습 요약**: 색상 테마와 Google Fonts를 적용해서 1회차 랜딩페이지를 나란히 비교한다.
- **누적 위치**: 1회차 랜딩페이지를 가져와 색·폰트만으로 다른 사이트처럼 변화시킴.

## 2. 슬라이드 8장

| # | 파일 | 유형 | goal |
|---|------|------|------|
| 01 | `01_오늘의_목표.svg` | 인트로 | 2회차 목표와 수업 흐름을 안내한다 |
| 02 | `02_색상이_분위기를_만든다.svg` | 개념 | 색상 유형(웜/쿨/뉴트럴/다크)과 분위기 관계를 이해한다 |
| 03 | `03_실습1_색상_테마_적용.svg` | 실습 | Claude에게 색상 테마를 지시해서 적용한다 |
| 04 | `04_폰트_선택의_원칙.svg` | 개념 | Serif/Sans-Serif/Display 폰트 분류와 선택 원칙을 이해한다 |

| 08 | `08_핵심_정리.svg` | 정리 | 2회차 핵심 3가지를 정리하고 3회차를 예고한다 |

### 슬라이드별 topics

- **02 색상 유형**: 웜(빨강·주황·노랑) / 쿨(파랑·보라·청록) / 뉴트럴(흰·회·검) / 다크 모드(어두운 배경 + 밝은 텍스트)
- **03 색상 테마 실습**: 색상 코드 없이 말로 지시 / 배경·텍스트·포인트 색상 명시 / before/after 변화 확인
- **04 폰트 원칙**: Serif(고급·신뢰감) / Sans-Serif(깔끔·현대적) / Display(강렬·임팩트)
- **05 Google Fonts**: link 태그 한 줄 추가 / font-family CSS 적용 / 폰트별 느낌 차이
- **06 비교**: 같은 HTML, 다른 CSS / CSS만으로 퀄리티 차이 / 말로 설명하면 Claude가 변환
- **07 나만의 조합**: 다크 테크 / 밝은 감성 / 내추럴 조합 / 자연어 수정 요청
- **08 정리**: 색상 언어(말로 설명) / Google Fonts(이름만) / Before/After(CSS만으로)

### 실습 프롬프트

| 실습 | 프롬프트 |
|------|---------|
| 03 색상 테마 | 위 HTML에 색상 테마를 적용해줘. 배경 #0f172a, 텍스트 흰색, 포인트 색상 #38bdf8으로. |
| 05 Google Fonts | 위 페이지에 Google Fonts의 Noto Sans KR 폰트를 적용해줘. |
| 07 나만의 조합 | 1회차 랜딩페이지에 배경 #1a1a2e, 포인트 #e94560, Noto Sans KR 폰트 적용해줘. |
