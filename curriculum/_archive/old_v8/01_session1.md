# Session 1 — 웹의 언어를 만나다

## 1. 회차 개요

- **시간**: 2시간
- **트랙**: Basic
- **목표**: HTML/CSS/JS의 역할을 이해하고 클로드 지시로 랜딩페이지를 완성한다.
- **핵심 topics**:
  - HTML — 뼈대 (구조)
  - CSS — 스타일 (디자인)
  - JS — 행동 (인터랙션)
  - 클로드에게 지시하는 기본 워크플로우
  - 투박하게 시작 → CSS 입히면서 달라지는 과정 체감
- **실습 요약**: 클로드로 랜딩페이지를 생성하고 CSS를 단계별로 추가하며 변화를 확인한다.
- **누적 위치**: **모든 회차의 베이스가 되는 첫 랜딩페이지를 만든다.**

### 슬라이드별 topics

- **02 역할 분담**: HTML = 뼈대(건물 기둥) / CSS = 피부·옷(인테리어) / JS = 근육·행동(엘리베이터) / 브라우저는 HTML→CSS→JS 순서로 읽음
- **03 HTML 뼈대 실습**: 구체적 항목 명시(이름·직업·소개글·버튼) / "스타일은 없이" 명시의 중요성 / 구조와 디자인 분리하면 수정이 쉬워진다
- **04 CSS 4대 영역**: 색상·배경 / 폰트·타이포 / 간격·여백 / 레이아웃·배치 / 지시→생성→확인→수정 4단계 사이클
- **05 CSS 입히기**: 같은 HTML — 완전히 다른 인상 / 어두운 배경·흰 글씨·파란 버튼 / CSS의 힘 시각적 확인
- **06 JS 역할**: HTML+CSS = 고정된 화면(사진) / JS = 사용자 행동에 반응 / click·scroll·mousemove 3대 트리거
- **07 JS 인터랙션**: 트리거(click) + 동작(메시지) 기본 패턴
- **08 정리**: 역할 분담 / 분리 지시(뼈대 먼저 → CSS 입히기) / 수정 사이클(반복하면서 완성)
