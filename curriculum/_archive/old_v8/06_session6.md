# Session 6 — 배경 효과와 순수 Canvas

## 1. 회차 개요

- **시간**: 2시간
- **트랙**: Basic
- **목표**: VANTA.js와 순수 Canvas 2D를 비교하며 각각의 인터랙티브 배경 효과를 구현한다.
- **핵심 topics**:
  - VANTA.js 6가지 효과 (WAVES/NET/BIRDS 등)
  - Canvas 2D API 기초 (beginPath/arc/fillRect)
  - 별자리 파티클 — 순수 JS 구현
  - 배경 효과 선택 가이드
  - 목적별 배경 추천
- **실습 요약**: VANTA.js 배경과 Canvas 2D 별자리 파티클을 각각 구현하고 나만의 배경을 완성한다.
- **누적 위치**: 지금까지 만든 포트폴리오에 배경 효과를 얹어 분위기 완성.

### 슬라이드별 topics

- **02 VANTA.js**: WAVES/NET/BIRDS/FLAMES/FOG/DOTS / backgroundColor + color / mouseControls
- **03 VANTA 적용**: VANTA.NET 효과 / 색상 커스텀 / 다른 효과로 교체 연습
- **04 Canvas 2D**: 픽셀 단위 드로잉 / beginPath/arc/fillRect / requestAnimationFrame 루프
- **05 별자리 파티클**: 파티클 생성·이동 / 가까운 점끼리 선 연결 / 마우스 반발 효과
- **06 선택 가이드**: 포트폴리오(VANTA WAVES/NET) / 스타트업(Canvas 파티클) / 크리에이티브(VANTA FLAMES/BIRDS)
- **07 나만의 배경**: 효과 선택 + 색상 설정 / 텍스트 가독성 확인 / 1~6회차 통합 확인
- **08 정리**: VANTA(3D 배경도 이름만) / Canvas(원+선 = 모든 효과) / 배경 선택(분위기를 만든다)

### 실습 프롬프트

| 실습 | 프롬프트 |
|------|---------|
| 03 VANTA | 히어로 섹션 배경에 VANTA.NET 효과를 적용해줘. 어두운 배경에 하늘색 네트워크 선이 움직이도록. |
| 05 별자리 파티클 | Canvas로 별자리 파티클 배경을 만들어줘. 작은 점들이 천천히 움직이고, 가까운 점끼리 선으로 연결되며, 마우스에 반응하도록. |
| 07 나만의 배경 | 지금까지 만든 포트폴리오에 배경 효과를 적용해줘. |
