# Session 3 — 스크롤 트리거를 설계한다

## 1. 회차 개요

- **시간**: 2시간
- **트랙**: Basic
- **목표**: JS 트리거 개념을 이해하고 GSAP ScrollTrigger로 스크롤 인터랙션을 구현한다.
- **핵심 topics**:
  - 스크롤 트리거 개념
  - GSAP ScrollTrigger CDN 로드
  - 페이드인 효과 구현
  - 수평 스크롤 원리 (pin + translateX)
  - 텍스트 컬러 reveal (progress 0~1)
- **실습 요약**: GSAP ScrollTrigger로 페이드인, 수평 스크롤, 텍스트 컬러 reveal 효과를 구현한다.
- **누적 위치**: 1·2회차 랜딩페이지에 스크롤 인터랙션 3종을 얹는다.

| 02 | `02_스크롤_트리거_개념.svg` | 개념 | 스크롤 트리거의 동작 원리와 GSAP 라이브러리를 이해한다 |

### 슬라이드별 topics

- **02 트리거 개념**: 스크롤 위치 감지 / 요소 진입 시 트리거 발동 / GSAP ScrollTrigger 소개
- **03 ScrollTrigger 기본**: CDN script 태그 추가 / 요소 진입 시 페이드인 / from/to 애니메이션 설정
- **04 수평 스크롤 원리**: 세로 스크롤 → 가로 이동 변환 / pin + translateX 패턴 / 갤러리·스텝별 소개에 활용
- **05 수평 스크롤 구현**: pin으로 섹션 고정 / translateX로 가로 이동 / scrub으로 부드러운 연결
- **06 reveal 원리**: 스크롤 진행률 0~1 / 회색 → 검정 / 스토리텔링 효과
- **07 reveal 구현**: progress와 색상 연결 / 0%=회색 / 100%=검정 / 한 단어씩 순서 reveal
- **08 정리**: 트리거(위치가 애니메이션을 켠다) / 수평 스크롤(방향을 바꾼다) / Reveal(숫자로 상태 정의)

### 실습 프롬프트

| 실습 | 프롬프트 |
|------|---------|
| 03 페이드인 | 1회차 랜딩페이지에 GSAP ScrollTrigger를 추가해줘. 각 섹션이 스크롤할 때 아래에서 위로 페이드인 되도록. |
| 05 수평 스크롤 | 작품 갤러리 섹션을 추가해줘. 카드 4개가 가로로 나열되고, 세로로 스크롤하면 옆으로 이동하는 수평 스크롤 효과. |
| 07 텍스트 reveal | 히어로 섹션의 헤드라인 텍스트를 스크롤 reveal 효과로 만들어줘. 스크롤 진행률에 따라 글자가 회색에서 검정으로 밝아지도록. |
