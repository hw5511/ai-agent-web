# Session 7 — 기획이 곧 프롬프트다

## 1. 회차 개요

- **시간**: 2시간
- **트랙**: Basic
- **목표**: 좋은 프롬프트와 나쁜 프롬프트의 차이를 직접 비교하고 4요소 구체적 작성법을 익힌다.
- **핵심 topics**:
  - 나쁜 패턴: 모호한/추상적/범위없는 지시
  - 좋은 패턴: 구체적 수치/참고 키워드/범위 명시
  - 4요소: 대상 + 스타일 + 수치 + 범위
  - 프롬프트 수준별 결과 비교
  - 1~6회차 통합 랜딩페이지 실습
- **실습 요약**: 나쁜/좋은 프롬프트를 각각 체험하고 4요소를 갖춘 통합 랜딩페이지를 완성한다.
- **누적 위치**: 1~6회차의 기술을 모두 통합한 첫 완성본 만들기.

| 08 | `08_핵심_정리.svg` | 정리 | 7회차 핵심 3가지를 정리하고 8회차를 예고한다 |

### 슬라이드별 topics

- **02 나쁜 vs 좋은**: 나쁜(모호함·추상적·범위없음) / 좋은(구체적 수치·참고·범위 명시) / 패턴 인식 훈련
- **03 나쁜 체험**: "예쁘게 만들어줘" 지시 / Claude의 임의 해석 / 수정 반복의 비효율
- **04 4요소 구조**: 대상(무엇을) / 스타일(어떤 느낌) / 수치(구체적 값) / 범위(어디까지)
- **05 4요소 실험**: 첫 시도 완성률 UP / 수정 횟수 DOWN / 4요소 직접 작성
- **06 차이 분석**: 퀄리티 4요소(레이아웃·타이포·색상 대비·인터랙션) / 수준별 수정 횟수 / 5분 투자 = 30분 절약
- **07 통합 실습**: VANTA 배경 + Typed.js / GSAP 스크롤 효과 / 색상 팔레트 + 폰트
- **08 정리**: 나쁜 프롬프트(구체성 없으면 결과 없다) / 4요소(갖추면 원하는 결과) / 통합 실습(프롬프트가 곧 기획)

### 실습 프롬프트

| 실습 | 프롬프트 |
|------|---------|
| 03 나쁜 체험 | 웹사이트를 예쁘고 고급스럽게 만들어줘. |
| 05 4요소 실험 | 히어로 섹션의 배경(대상)을 다크 테크 스타일(스타일)로 바꿔줘. 배경 #0f172a, 텍스트 흰색, 포인트 #38bdf8(수치). CSS만 수정해줘(범위). |
| 07 통합 랜딩 | 포트폴리오 랜딩페이지를 완성해줘. 히어로: VANTA 배경 + Typed.js 직함, 스크롤: GSAP 페이드인, 색상: 다크 테크(#0f172a + #38bdf8) + Noto Sans KR. |
