# Session 5 — 스크롤 라이브러리 (GSAP)

## 회차 개요

- **시간**: 2시간
- **트랙**: Basic / Part 1
- **1개념**: **스크롤 트리거 — GSAP ScrollTrigger**
- **목표**: GSAP ScrollTrigger로 페이드인 / 수평 스크롤 / 텍스트 컬러 reveal 3가지 패턴을 구현한다.
- **누적 위치**: 4주 단순 JS 스크롤 → 5주 라이브러리 풀 활용으로 시네마틱 페이지.
- **회차 끝 학생 상태**: 시네마틱한 스크롤 페이지 (3가지 효과 포함)

### 슬라이드별 topics

- **02 라이브러리**: script 태그 1줄 = 수천 줄 기능 / 이름만 알면 Claude가 사용법 / GSAP 소개
- **03 페이드인**: gsap.from / ScrollTrigger 옵션 / 섹션 진입 시 자동
- **04 수평 원리**: 세로 스크롤을 가로 움직임으로 변환 / 갤러리·스텝 소개에 활용
- **05 수평 실습**: pin으로 섹션 고정 / translateX 매핑 공식 / scrub으로 부드러운 연결
- **06 reveal 원리**: 스크롤 진행률 0~1 / 색·크기·위치 등 수치로 표현
- **07 reveal 실습**: 헤드라인 글자 색이 회색→검정 단계별 변화
