## 학생 프로파일

| 영역 | 수준 |
|------|------|
| HTML / CSS / JS | ❌ zero |
| React | ❌ zero (메타 인식만) |
| **Claude Code 도구** | ✅ 익숙 (선수강 완료) |
| **하네스 엔지니어링** | ✅ 익숙 |
| **컨텍스트·프롬프트 엔지니어링** | ✅ 익숙 |

→ "일반 코딩 zero"가 아니라 **"AI 도구 능숙한 zero"**. 학습 곡선이 일반 코딩 입문보다 빠를 수 있음.

각 회차는 **단 하나의 핵심 개념**을 다룬다. 학생이 한 회차 후 "오늘 뭘 배웠는지" 한 문장으로 말할 수 있어야 함.

| 9 | API 연동 (fetch) |

| 12 | 사용자 인증 |
| 13 | 내 도메인 가지기 |
| 14 | Vercel 환경으로 옮기기 |
