# Session 3 — CSS, 디자인 (색·폰트·여백)

## 회차 개요

- **시간**: 2시간
- **트랙**: Basic / Part 1
- **1개념**: **스타일 = CSS**
- **목표**: 색상 팔레트 + Google Fonts + 여백 제어로 2회차 뼈대를 완전히 다른 페이지로 리디자인한다.
- **누적 위치**: HTML 뼈대(2주) 위에 CSS만 얹어 분위기 변환 → "CSS의 힘" 체감.
- **회차 끝 학생 상태**: Before(2주차) vs After(3주차) 나란히 비교 가능한 리디자인된 페이지

### 슬라이드별 topics

- **02 4대 영역**: 색·배경 / 폰트·타이포 / 간격·여백 / 레이아웃·배치
- **03 색상 유형**: 웜(빨강·주황) / 쿨(파랑·청록) / 뉴트럴(흰·회·검) / 다크(어두운 배경+밝은 텍스트)
- **04 색상 실습**: "다크 테크 분위기로" / 배경·텍스트·포인트 색 자연어로 지시
- **05 폰트 분류**: Serif(고급·신뢰) / Sans-Serif(깔끔·현대) / Display(강렬·임팩트)
- **06 Google Fonts**: link 한 줄 + font-family 적용 / 한글+영문 조합 (Noto Sans KR + Inter)
- **07 여백**: 답답한 페이지 vs 숨통 트인 페이지 / padding·margin 한 줄로 인상 변화
