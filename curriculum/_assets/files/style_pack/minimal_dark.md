# DESIGN.md — Minimal Dark (미니멀 다크)

> 스타일 가이드 예시 1/3. 강사 우희가 만든 교육용 프리셋(원본 창작, 특정 브랜드 비공인).
> 사용법: 이 파일을 프로젝트 폴더에 `CLAUDE.md` 라는 이름으로 저장한 뒤 "이 스타일로 내 페이지 만들어줘" 라고 Claude Code에 말하세요.

## 무드 (Mood)
- 한밤의 테크 제품 사이트. 차분하고 고급스럽고 절제됨.
- 여백이 주인공. 요소는 적게, 간격은 넉넉하게.

## 색 (Colors)
- background: #0a0a0a (거의 검정)
- surface: #161616 (카드)
- text-primary: #fafafa
- text-muted: #a1a1aa
- accent: #6366f1 (인디고, 포인트 한 곳에만)
- border: #262626

## 타이포 (Typography)
- 헤드: Inter, 700, 자간 -0.02em, 크게 (48px+)
- 본문: Inter, 400, 행간 1.7
- 한글: Pretendard

## 간격 (Spacing)
- 섹션 상하 여백: 매우 크게 (120px+)
- 콘텐츠 최대폭: 720px, 가운데 정렬

## 인터랙션 (Interaction)
- hover 시 아주 미세한 밝기 변화만 (0.15s ease)
- 스크롤 시 요소가 아래에서 위로 부드럽게 페이드인

## 금지 (Avoid)
- 그림자 남발, 화려한 그라데이션, 둥근 모서리 과다
