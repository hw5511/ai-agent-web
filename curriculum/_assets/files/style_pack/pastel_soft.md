# DESIGN.md — Pastel Soft (파스텔 소프트)

> 스타일 가이드 예시 2/3. 강사 우희가 만든 교육용 프리셋(원본 창작, 특정 브랜드 비공인).
> 사용법: 이 파일을 프로젝트 폴더에 `CLAUDE.md` 라는 이름으로 저장한 뒤 "이 스타일로 내 페이지 만들어줘" 라고 Claude Code에 말하세요.

## 무드 (Mood)
- 따뜻하고 친근한 라이프스타일 브랜드. 부드럽고 말랑한 느낌.
- 둥근 모서리와 파스텔톤이 주는 안정감.

## 색 (Colors)
- background: #fdf6f0 (크림)
- surface: #ffffff
- text-primary: #3d3a4e
- text-muted: #8b879c
- accent-1: #f9a8d4 (핑크)
- accent-2: #a7d8f0 (하늘)
- border: #f0e6dd

## 타이포 (Typography)
- 헤드: Poppins, 600, 자간 0
- 본문: Pretendard, 400, 행간 1.8
- 둥글둥글한 산세리프 선호

## 간격 (Spacing)
- 카드 모서리: rx 24 (아주 둥글게)
- 요소 간 여백: 부드럽게 넉넉히

## 인터랙션 (Interaction)
- hover 시 살짝 떠오르며(translateY -4px) 부드러운 그림자
- 버튼은 둥근 알약 형태(pill)

## 금지 (Avoid)
- 날카로운 직각, 강한 대비, 차가운 톤
