# Session 10 — 데이터 저장 (스키마 개념 + LocalStorage)

## 회차 개요

- **시간**: 2시간
- **트랙**: 심화 / Part 2
- **1개념**: **데이터 구조화 + 저장**
- **목표**: DB 스키마(컬럼 설계) 개념을 이해하고 LocalStorage로 폼 데이터를 브라우저에 저장·재표시한다.
- **누적 위치**: 9주(데이터 가져오기) → 10주(저장하기) → 11주(클라우드 DB)로 자연스러운 진행.
- **회차 끝 학생 상태**: 폼에 입력하면 저장되고 새로고침해도 남아있는 페이지

### 슬라이드별 topics

- **02 구조화**: 메모장에 흩어진 정보 vs 엑셀 표 / 검색·필터·정렬 가능 차이
- **03 스키마**: 컬럼 이름(name·email·message) / 타입(텍스트·숫자·날짜) / 선택 옵션
- **04 설계 실습**: "내 페이지에 방명록을 만든다면 어떤 컬럼이 필요할까?" Claude와 대화
- **05 LocalStorage**: key-value 저장 / JSON.stringify·parse / 5MB 제한
- **06 폼 저장**: HTML form / submit 이벤트 / LocalStorage 배열에 push
- **07 삭제·수정**: 인덱스로 항목 찾기 / 배열 조작
- **08 한계**: "내 컴퓨터에서만 보임" / 다음 주 클라우드 DB로 해결
