# AI Agent Web — SVG 슬라이드 스타일 가이드

> **분석 범위**: `assets/basic/step01` ~ `step08` 전 8개 폴더, 총 67장 SVG 중 대표 18장 정밀 분석
> **목적**: 9~16주차 신규 슬라이드 제작 시 동일 톤 유지 (강사 수기 작성 + Claude 위임 작성 모두 활용)
> **캔버스 표준**: `1280 x 720` (16:9, 슬라이드 비율)

---

## 1. 전체 톤·디자인 시그니처

한마디로 정리하면 **"화이트 미니멀 + 노션·애플 키노트 풍 + 카테고리별 파스텔 카드"** 스타일이다.

### 시그니처 특징
1. **흰 배경 (`#ffffff`)이 절대 다수** — step01~step08 모든 슬라이드의 베이스. 다크 배경은 *코드 박스*와 *하단 강조 배너*에서만 부분적으로 사용
2. **상단 흑색 배지 (`WEB 01`~`WEB 08`)** — 모든 슬라이드 좌상단 (60, 44)에 고정. 회차 식별의 시그니처
3. **하단 흑색 강조 배너 (`#171717`)** — 모든 슬라이드 마지막 줄에 "오늘의 한 줄 메시지" 형식
4. **카테고리 = 색상** 1:1 매핑 — 노랑(HTML/01), 파랑(CSS/02), 초록(JS/03), 보라(특수)
5. **모서리 라운드** — 카드 `rx=12~16`, 배너 `rx=10`, 배지 `rx=12` (완전 둥글지 않은 부드러움)
6. **음영 거의 없음** — `filter`/`shadow` 사용 0건. 색상과 테두리만으로 깊이 표현
7. **시스템 폰트만 사용** — 별도 웹폰트 로드 없음, 모든 환경 호환

### 대표 시그니처 예시
- 상단 배지: `step01/01_오늘의_목표.svg` 라인 3~4
- 하단 배너: `step01/08_핵심_정리.svg` 라인 33~34

## 2. 색상 시스템

전체 슬라이드에서 사용되는 hex는 약 30개로 수렴되며, **카테고리별 색상 패밀리**가 명확하다.

### 2.1 기본 컬러 (그레이스케일)

| 역할 | Hex | 용도 |
|---|---|---|
| 배경 | `#ffffff` | 슬라이드 베이스 |
| 본문 텍스트 | `#171717` | 제목, 흑색 배지·배너 |
| 보조 텍스트 | `#374151` | 본문 중간 강조 |
| 부드러운 본문 | `#6b7280` | 부제, 설명 |
| 메타 라벨 | `#9ca3af` | "오늘 배울 것" 등 섹션 라벨 |
| 카드 배경 | `#f9fafb` | 중립 카드 |
| 옅은 회색 | `#f3f4f6` | 보조 배너 |
| 테두리 | `#e5e7eb` | 카드·구분선 기본 테두리 |
| 약한 테두리 | `#d1d5db` | 보조 테두리 |

### 2.2 카테고리 색상 패밀리 (5종 + 보조 2종)

각 패밀리는 **{배경(매우 옅음) / 테두리(중간) / 메인 텍스트(진함) / 액센트(가장 진함)}** 4단계로 구성된다.

| 패밀리 | 배경 | 테두리 | 메인 텍스트 | 액센트(타이틀) | 대표 용도 |
|---|---|---|---|---|---|
| **노랑 (Amber)** | `#fef3c7` | `#fcd34d` | `#92400e` / `#78350f` | `#d97706` | HTML, 실습, 카드 01 |
| **파랑 (Blue)** | `#dbeafe` | `#93c5fd` | `#1e40af` / `#1e3a8a` | `#2563eb` / `#1d4ed8` | CSS, 개념, 카드 02, **Claude 지시문 박스** |
| **초록 (Green)** | `#dcfce7` | `#86efac` | `#15803d` / `#166534` | `#16a34a` | JS, 연습/완료, 카드 03 |
| **분홍 (Pink)** | `#fce7f3` | `#f9a8d4` | `#9d174d` / `#be185d` | `#be185d` | 특수 카테고리, 카드 04 |
| **보라 (Violet)** | `#faf5ff` | `#d8b4fe` | `#6d28d9` | `#7c3aed` | 3D, 고급 주제 |
| 빨강 (Red, 보조) | `#fef2f2` | `#fca5a5` | `#991b1b` / `#b91c1c` | `#dc2626` | "나쁜 예", 경고 |
| 청록 (Teal, 보조) | `#042f2e` | `#0d9488` | — | `#99f6e4` | 다크 카드 (step06 FOG 등) |

### 2.3 특수 색상

- **Claude 지시문 박스 전용**: 배경 `#eff6ff`, 테두리 `#bfdbfe`, 텍스트 `#1e40af` (파랑 패밀리의 가장 옅은 버전)
- **연습해보세요 박스 전용**: 배경 `#f0fdf4`, 테두리 `#bbf7d0`, 텍스트 `#166534` (초록 패밀리의 가장 옅은 버전)
- **다크 코드 박스**: 배경 `#0f172a` 또는 `#1a1a2a` 또는 `#171717`, 코드 텍스트 `#a3e635`(라임/네온), 주석 `#6b7280`/`#94a3b8`
- **다크 강조 시 포인트색**: `#38bdf8` (밝은 하늘색) — 다크 배너 위에서 시그니처처럼 등장 (step02 03번, step06 02번, step08 11번)

### 2.4 색상 사용 규칙
1. 한 슬라이드에 카테고리 색상은 **최대 3~4개**까지만 (3카드/4카드 구도)
2. "01/02/03" 번호 카드는 거의 항상 **노랑→파랑→초록** 순서
3. 액센트 색상은 텍스트에만 적용, 배경은 항상 가장 옅은 톤
4. 다크 배경은 코드 / 강조 배너 / "변경 후(After)" 영역에서만

## 3. 폰트 시스템

### 3.1 폰트 패밀리 (단 하나)

모든 슬라이드에서 동일:
```
font-family="-apple-system,BlinkMacSystemFont,'Segoe UI',Arial,sans-serif"
```
- 한글/영문 통합 — 별도 한글 폰트 지정 없음 (시스템 폰트가 한글도 렌더링)
- 일부 슬라이드는 `<style>text { font-family: ... }</style>`로 일괄 적용 (step04, step05, step06, step07 일부)
- **모노스페이스 (코드 전용)**: `font-family="'Courier New', monospace"` — step05/06의 코드 박스에서만

### 3.2 폰트 사이즈 단계

| 단계 | 사이즈 | weight | 색상 | 용도 |
|---|---|---|---|---|
| H1 (제목) | `40` | `700` | `#171717` | 슬라이드 메인 제목 (실습은 `36`도 사용) |
| H2 (카드 타이틀 大) | `22` | `700` | 액센트 | 정리 슬라이드의 카드 타이틀 |
| H2 (개념 카드 大) | `42` | `900` | 액센트 | HTML/CSS/JS 같은 약어 강조 (step01/02) |
| H3 (카드 타이틀) | `16~20` | `700` | 액센트 또는 `#171717` |  일반 카드 제목 |
| Body L (부제) | `19` | `400` | `#6b7280` | 슬라이드 부제 |
| Body M (본문) | `14~16` | `400~600` | `#374151`/패밀리 색 | 일반 본문 |
| Body S (카드 설명) | `13~14` | `400` | `#6b7280` 또는 패밀리 옅은 색 | 카드 내 보조 설명 |
| Caption | `12~13` | `400~600` | `#9ca3af`/패밀리 옅은 색 | 메타, 캡션 |
| Label (섹션 라벨) | `13~14` | `600` | `#9ca3af` | "오늘 배울 것", `letter-spacing: 0.04~0.08em` |
| Badge | `11` | `700` | `#ffffff` 또는 액센트 | 상단 배지 (`letter-spacing: 0.05em`) |
| Number (큰 번호) | `28~40` | `700~900` | 액센트 | 정리 카드의 "01/02/03" |
| 배너 본문 | `15~17` | `600` | `#ffffff` | 하단 흑색 배너 메시지 |

### 3.3 폰트 사용 규칙
- 한글 가중치: 굵기는 `700` 또는 `400` 두 단계가 주력 (`600`은 라벨 전용)
- `letter-spacing`은 **배지·라벨·영문 약어**(WEB 01, 오늘 배울 것)에만 `0.04~0.08em` 적용. 한글 본문엔 적용 X
- 번호 카드의 큰 숫자는 `font-weight="900"`까지 사용 (정리 슬라이드의 시그니처 표현)

## 4. 레이아웃 시스템

### 4.1 캔버스 & 마진
- **viewBox**: `0 0 1280 720` (전 슬라이드 동일)
- **좌우 마진**: `60px` — 모든 본문 요소의 좌측 x값은 `60`, 우측 끝은 `1220` (콘텐츠 너비 = 1160px)
- **상단 마진**: 배지 `y=44`, 제목 `y=130`, 부제 `y=178`
- **하단 마진**: 배너의 바닥은 보통 `y=670~676` (캔버스 하단에서 약 44~50px 위)

### 4.2 표준 헤더 블록 (모든 슬라이드 공통)

```
y=44   상단 배지 (66x24, 흑색) "WEB 0X"
y=44   (실습 시) 두 번째 배지 (52x24, 노랑) "실습 N"  ← x=144부터
y=130  제목 (font-size=40, weight=700)
y=178  부제 (font-size=19, color=#6b7280)
y=212  구분선 (x=60~1220, stroke=#e5e7eb)
y=240~ 본문 영역 시작
```

### 4.3 본문 그리드 패턴

콘텐츠 영역(`y=240` ~ `y=600`)은 가용 너비 1160px을 다음 그리드 중 하나로 분할:

| 분할 | 카드 너비 | x 좌표 (좌→우) | 간격 | 대표 슬라이드 |
|---|---|---|---|---|
| **3분할** (가장 흔함) | 340 또는 350 | `60, 430/460, 800/860` | 30~50px | step01 01번/08번, step05 08번 |
| **2분할** | 530~560 | `60, 660` | 70~100px | step06 04번, step07 04번 |
| **4분할 (2x2)** | 530 x 160 | `60·660` × `240·430` | 70px | step07 04번 |
| **단일 와이드** | 1160 | `60` | — | Claude 지시문 박스 (step01 03번, step02 03번) |
| **수직 스택** | 800 (중앙정렬) | `240` | y간격 30px | step03 02번 (3단계 흐름) |
| **흐름 칩** | 120 x 36 | `60, 212, 364…` 152px 간격 | 화살표 16px | step02 01번 (이론→실습 흐름) |

### 4.4 카드 표준 사양

| 종류 | width × height | rx | stroke-width |
|---|---|---|---|
| 인트로 3카드 | `340 × 110` | 12 | 1~1.5 |
| 개념 3카드 | `350 × 330` (큰 카드) | 16 | 2 |
| 정리 3카드 | `350 × 290` (or 340) | 16 | 1~2 |
| 실습 코드/지시문 박스 | `1160 × 90~110` | 12 | 1~1.5 |
| 흐름 단계 칩 | `120 × 36` | 8 | 1 |
| 동작 원리 박스 | `800 × 64` (중앙) | 10 | 1 |
| 하단 강조 배너 | `1160 × 48~56` | 10~12 | — |

### 4.5 여백 규칙
- 카드 내부 패딩: 좌우 20~30px, 상단 텍스트는 카드 top + 38~58px (제목 위치)
- 카드 간 가로 간격: 30px (3카드 기준)
- 섹션(라벨 + 콘텐츠) 사이 세로 간격: 약 50~70px
- 라벨 → 첫 콘텐츠: 14~24px

## 5. 슬라이드 유형별 패턴

각 회차는 **8장 구조**가 표준 (step08만 11장 예외).

### 유형 A — `01_오늘의_목표.svg` (인트로)
**구조**: 헤더 → "오늘 배울 것" 라벨 → **3장의 미니 카드** (340×110, 회색계 또는 카테고리 색) → "수업 흐름" 라벨 → 흐름 칩(이론→실습→…→정리) 또는 한 줄 텍스트 → 하단 흑색 배너

**핵심 요소**:
- 미니 카드 3개에 회차의 큰 학습 목표 3개
- 흐름 표현: 칩 7~10개를 `→` 화살표로 연결 (step02), 또는 한 줄 텍스트로 압축 (step01)
- 하단 배너 문구는 회차의 한 줄 약속/슬로건

**참조**: `step01/01_오늘의_목표.svg`, `step02/01_오늘의_목표.svg`, `step07/01_오늘의_목표.svg`

### 유형 B — `02_*` `04_*` `06_*` (개념 슬라이드)
**구조**: 헤더 → 라벨("동작 원리"/"VANTA 효과 종류"/카테고리명) → 다이어그램 영역 → 하단 배너

**다이어그램 스타일**:
1. **3카드 평행 비교** (역할 분담, 종류 나열): 큰 카드 3개에 약어(HTML/CSS/JS), 비유, 불릿 3개
2. **수직 스텝 다이어그램** (원리/흐름): 800px 박스 3~4개를 `↓` 또는 `→`로 연결, 각 단계 색상은 회색→파랑→초록 등 점진 변화
3. **2분할 비교** (Before vs After, 일반 vs 특수): 좌측 라이트 카드 + 우측 다크 카드
4. **2x2 매트릭스** (4요소): step07 좋은 프롬프트 4구성

**참조**: `step01/02_HTML_CSS_JS_역할분담.svg` (3카드), `step03/02_스크롤_트리거_개념.svg` (수직 스텝), `step06/04_Canvas_2D_기초.svg` (2분할), `step07/04_좋은_프롬프트_구조.svg` (2x2)

### 유형 C — `03_실습1_*` `05_실습2_*` `07_실습3_*` (실습 슬라이드)
**구조 표준**:
1. 헤더 (상단에 노랑 "실습 N" 배지 추가, x=144)
2. **Claude 지시문 박스** — `1160 × 90~110`, 배경 `#eff6ff`, 테두리 `#bfdbfe`, 안에 파랑 배지("Claude 지시문") + 파란색 텍스트(`#1e40af`/`#1d4ed8`)로 큰따옴표 감싼 프롬프트
3. 중간 영역 — "이 지시문의 핵심" 또는 "동작 원리" 또는 "변화 포인트" 라벨 + 박스 2~3개
4. **연습해보세요 박스** — `1160 × 80`, 배경 `#f0fdf4`, 테두리 `#bbf7d0`, 초록 배지 + 초록색 불릿 텍스트
5. 하단 회색 배너 (`#f3f4f6`) 또는 흑색 배너 — 캐주얼 격려 문구

**지시문 박스 핵심**: 따옴표(`"..."`)로 감싸고 파란색 텍스트, 길이는 1~2줄
**연습 박스 핵심**: `•` 불릿 2개, 한 줄에 80~90자 내외

**참조**: `step01/03_실습1_HTML_뼈대_생성.svg`, `step02/03_실습1_색상_테마_적용.svg`, `step02/05_실습2_Google_Fonts_적용.svg`, `step04/03_실습1_마그네틱_버튼.svg`

### 유형 D — `08_핵심_정리.svg` (정리)
**구조**: 헤더 (제목="N회차 핵심 정리", 부제="오늘 배운 것 3가지") → **3장의 큰 카테고리 카드** (350×290) → 하단 흑색 배너 ("다음 N+1회차 — …")

**카드 내부 표준**:
- 상단 큰 숫자 `01` (font-size=28~40, weight=700~900, 액센트 색)
- 큰 타이틀 (font-size=18~22, weight=700)
- 카드 내부 가로선 (stroke=패밀리 테두리색)
- 본문 3줄 (불릿 없이 중앙정렬)
- 카드 하단에 한 줄 슬로건 (font-weight=600, 액센트 색)

**카드 색상은 항상 노랑→파랑→초록 순서**, 하단 배너는 다음 회차 예고

## 7. 한국어·영문 혼용 규칙

### 7.1 한글 vs 영문 비율
- **제목 (h1)**: 한국어 90% + 약어 영문 (`HTML · CSS · JS 역할 분담`, `VANTA.js — 클릭 한 번으로 3D 배경`)
- **부제**: 100% 한국어
- **카드 타이틀**: 한국어 (단, 기술명/약어는 그대로 — `HTML`, `Google Fonts`, `tsParticles`, `Three.js`)
- **본문**: 100% 한국어 + hex 코드/CSS 값 인라인 (`#0f172a`, `font-size 48px`)
- **배지**: 영문 (`WEB 01`, `Claude 지시문`은 한국어, `연습해보세요`도 한국어)
- **코드 박스**: 100% 코드 그대로 (영문)

### 7.2 어투
- **친근하면서 단호** — `"…한다"` 또는 `"…합니다"` 혼용. 인트로/실습은 `합니다`체, 개념/정리는 `…한다`체 자주
- 격려 문구: 캐주얼 (`코드를 몰라도 됩니다 — Claude가 대신 씁니다`, `결과물이 투박해도 괜찮습니다`)
- 슬로건: 짧고 강한 한 줄 (`프롬프트가 곧 기획서다`, `위치가 애니메이션을 켠다`, `v12는 결과가 아닌 과정을 바꾼다`)

### 7.3 기호/이모지
- **이모지는 0건** (한 슬라이드도 사용 안 함)
- 사용되는 기호: `→`, `↓` (흐름), `•` (불릿), `·` (가운뎃점, 제목 구분 - `HTML · CSS · JS`), `—` (전각 대시, 부제·제목 부연)
- 따옴표: 한국어용 곡선 따옴표(`" "`)와 직선 따옴표(`" "`) 혼용 (지시문 박스는 보통 곡선)

### 7.4 위트 패턴
- 비유 활용 (HTML=뼈대=건물의 기둥과 벽, CSS=피부·옷=인테리어와 도색, JS=근육·행동=엘리베이터와 자동문)
- 대조 구문 ("같은 HTML, 완전히 다른 결과", "코드를 몰라도 — Claude가 대신")

## 8. 9~16주 신규 슬라이드 제작 가이드

9~16주는 데이터·DB·도메인·Vercel·결제 같은 새 주제이지만, **시각 톤은 1~8주와 동일**해야 한다. 아래 체크리스트를 따라 만들 것.

### 8.1 회차 단위 작업 시 (한 회차 = SVG 8장)
1. **회차 번호 매핑**: 상단 배지는 `WEB 09`~`WEB 16`. fill/letter-spacing/위치 모두 동일.
2. **회차 색상 부여 X** — 회차마다 고유색을 정하지 말 것. 각 슬라이드 안에서 카테고리 색(노랑/파랑/초록/분홍/보라)을 그때그때 사용.
3. **8장 구성 유지**: `01_오늘의_목표 / 02_개념 / 03_실습1 / 04_개념 / 05_실습2 / 06_개념 / 07_실습3 / 08_핵심_정리`
4. step08처럼 11장으로 늘려도 좋지만 기본은 8장 권장

### 8.2 슬라이드 한 장 만들 때 공통 체크리스트
- [ ] viewBox = `0 0 1280 720`
- [ ] 배경 흰색 `<rect width="1280" height="720" fill="#ffffff"/>`
- [ ] 상단 배지 (60, 44) "WEB 0X" 흑색
- [ ] 제목 y=130, font-size=40, weight=700, fill=`#171717`
- [ ] 부제 y=178, font-size=19, fill=`#6b7280`
- [ ] 구분선 y=212, x=60→1220, `#e5e7eb`
- [ ] 좌우 마진 60px 준수
- [ ] 하단 강조 배너 (`#171717` 또는 `#f3f4f6`)
- [ ] 시스템 폰트만 사용 (`-apple-system,BlinkMacSystemFont,'Segoe UI',Arial,sans-serif`)
- [ ] 이모지 사용 금지

### 8.3 새 주제 색상 매핑 제안 (9~16주)

기존 카테고리 색을 새 주제에 일관 매핑하면 시각적 통일성이 유지된다:

| 새 주제 영역 | 추천 색상 패밀리 | 이유 |
|---|---|---|
| 데이터·DB (구조) | **노랑(Amber)** | HTML(구조)과 같은 "뼈대" 비유 |
| 백엔드·API (동작) | **초록(Green)** | JS와 같은 "행동" 카테고리 |
| 인증·보안 | **빨강(Red)** | 기존 "주의/경고" 패밀리 활용 |
| 결제·금융 | **보라(Violet)** | "고급/특수" 카테고리 |
| 도메인·배포(Vercel) | **파랑(Blue)** | CSS와 같은 "외형/포장" |
| AI·LLM 통합 | **청록 다크(`#042f2e` 계열)** | 다크 카드 활용 |
| 분석·로그 | **분홍(Pink)** | 미사용 슬롯, 신선함 |

**원칙**: 한 회차 내에서 카테고리 3개 이내로 제한. 정리 슬라이드는 항상 노랑→파랑→초록 순서.
