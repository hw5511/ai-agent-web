> **목적**: 16회차 전 슬라이드(147장)를 동일한 미니멀 PPT 톤으로 재생성한다.

## 1. 전체 톤·시그니처 (요약)

> **미니멀 PPT (애플 키노트 / Linear / Vercel 톤) — 흑백이 95%, 그린 한 점만**

- **흰 배경 (#ffffff)** 절대 다수, 모든 슬라이드 베이스
- **상단 흑색 배지 `WEB 01` ~ `WEB 16`** — 회차 식별, 좌상단 (60,44) 고정
- **하단 검은 배너 폐기** — 핵심 메시지는 본문/정리 슬라이드 큰 글자로 흡수
- **카테고리 색 폐기** — HTML=노랑, JS=초록 같은 분류색 사용 금지
- **카드는 흰 배경 + 회색 테두리(#e5e7eb)만** — 색 배경 카드 0
- **그린 #16a34a는 슬라이드당 1~2회만** — 표지 언더라인 / 핵심 한 줄 / 정리 구분선
- **이모지·shadow·filter 0**, 시스템 폰트만, 코드박스 사용 X (코드를 슬라이드에 직접 노출하지 않음)
- **여백이 콘텐츠** — 상하 60px 이상 숨 쉬는 공간 확보

## 5. 슬라이드 6종 템플릿

회차별 슬라이드 목차(`curriculum/_slides/NN_sessionN_slides.md`)의 `유형` 필드와 1:1 매핑.

### 5.1 표지 (16장) — 가장 미니멀

**시각 의도**: 한 호흡 쉬고 회차 시작. 정보 최소, 큰 여백.

```
┌─────────────────────────────────────────────┐
│ [WEB 01]                                    │  ← (60,44)
│                                             │
│                                             │
│                                             │
│  16주의 시작                                 │  ← (60, 280) size=20 #9ca3af 부제 위에 (선택)
│  AI로 웹 만드는 세계                          │  ← (60, 340) size=56~64 700 #171717
│  ─────                                       │  ← (60, 380) 120×4 rx=2 fill="#16a34a"
│                                             │
│                                             │
│                                             │
└─────────────────────────────────────────────┘
```

- 카드 0개, 로드맵 0개, 진행도 0
- 그린은 짧은 언더라인 1개만 (120×4 직사각형)
- 부제는 선택 (한 줄, 회색)

### 5.2 학습목표 (16장) — em-dash 글머리

**시각 의도**: 오늘 끝나면 할 수 있는 것 3~5개. 글머리 기호로.

```
┌─────────────────────────────────────────────┐
│ [WEB 01]                                    │
│                                             │
│ 학습 목표                                    │  ← y=130 size=40
│ 오늘 끝나면 할 수 있는 것                     │  ← y=178 size=19 #6b7280
│ ─────────────────────────────────            │  ← y=212 구분선
│                                             │
│   ─  Claude Code로 첫 페이지를 만든다         │  ← y=280, ─ x=80, 텍스트 x=120
│                                             │
│   ─  HTML 구조의 의미를 안다                  │  ← y=340
│                                             │
│   ─  랜딩페이지가 뭔지 설명할 수 있다         │  ← y=400
│                                             │
└─────────────────────────────────────────────┘
```

- em-dash `─` (U+2500) 글머리, size=22 #9ca3af
- 항목 텍스트: size=22 weight=500 #171717
- 행간 60~70px (PPT 답게 넓게)
- 마지막 항목 1개만 그린 #16a34a로 강조 가능 (선택)

### 5.3 개념 (50장) — 케이스 분기

#### 5.3.1 정의/설명 → 글머리

```
│ HTML이란 무엇인가                             │  ← y=130 size=40
│ 웹 페이지의 뼈대를 짜는 언어                    │  ← y=178 부제
│ ──────                                       │
│                                              │
│   ─  눈에 보이는 모든 것의 골격                  │  ← em-dash 글머리
│   ─  태그로 의미를 표시                         │
│   ─  꾸미기 전에 먼저 뼈대                       │
│                                              │
│   "구조가 먼저, 디자인은 나중"                  │  ← 우하단 or 중앙 큰 한 줄
│                                                  size=28 #16a34a 강조
└─────────────────────────────────────────────┘
```

#### 5.3.2 비교/분류 → 모노톤 카드 (2~5장)

```
│ 시맨틱 태그 5종                              │
│ ──────                                       │
│                                              │
│  ┌────────┐  ┌────────┐  ┌────────┐         │  ← 각 카드 200×120 rx=12
│  │ header │  │  nav   │  │  main  │         │     fill=#ffffff stroke=#e5e7eb
│  │   머리  │  │  메뉴  │  │  본문  │         │     stroke-width=1.5
│  └────────┘  └────────┘  └────────┘         │
│  ┌────────┐  ┌────────┐                      │
│  │ aside  │  │ footer │                      │
│  └────────┘  └────────┘                      │
```

- 카드: 흰 배경 + #e5e7eb 1.5px 테두리 (모두 동일)
- 카드 제목: size=22 weight=700 #171717
- 카드 설명: size=15 #6b7280
- **카드 배경에 색 채우기 금지**

#### 5.3.3 다이어그램/플로우 → 박스 + 화살표

```
│ fetch와 JSON의 흐름                          │
│ ──────                                       │
│                                              │
│   ┌────────┐   →   ┌────────┐                │
│   │   내    │       │   외부  │                │  ← 흰 박스 + 회색선
│   │ 페이지  │   ←   │ 서비스 │                │
│   └────────┘       └────────┘                │
│        ↓ JSON                                │
│   화면에 표시                                  │  ← 강조 한 줄 (그린 가능)
```

- 화살표: `→` `↓` 문자 (size=28 #9ca3af)
- 라벨 텍스트: size=14 #6b7280

### 5.4 실습 (42장) — 단계 글머리 (코드박스 X)

```
│ 실습 1 · 첫 뼈대 생성                          │
│ ──────                                       │
│                                              │
│   단계                                         │  ← 메타 라벨
│                                              │
│   ─  새 폴더 만들기                            │
│   ─  Claude Code 열기                          │
│   ─  프롬프트 한 줄 복사·붙여넣기                │
│   ─  결과물 확인                               │
│                                              │
│   "코드는 Claude가, 의도는 내가"               │  ← 그린 강조 한 줄
```

- **코드 자체는 슬라이드에 노출 X** (프롬프트는 외부 액션박스에서 복사)
- 단계 글머리만, 4~6개 권장
- 우상단 액션박스(슬라이드 외부 헤더 영역)가 프롬프트 카피·외부 링크 담당

### 5.5 정리 (13장) — 핵심 + 다음 예고

```
│ 핵심 정리                                      │
│ ──────                                       │
│                                              │
│   오늘 가져갈 것                                │  ← 메타 라벨
│   ─  HTML은 뼈대                              │
│   ─  태그는 의미                              │
│   ─  Claude가 작성, 나는 의도                 │
│                                              │
│   ────                                       │  ← 그린 짧은 구분선 80×3
│                                              │
│   다음 회차 (WEB 02) · HTML 첫 실습             │  ← 회색 작은 글씨 #9ca3af
```

## 6. 강조색 그린 사용 규칙 (엄격)

- **슬라이드당 1~2회만** 그린 사용
- 사용 가능한 4가지
  1. 표지 언더라인 (120×4 직사각형)
  2. 정리 구분선 (80×3 직사각형)
  3. 핵심 메시지 1줄 텍스트 (size=24~32)
  4. em-dash 글머리 중 핵심 1개만 (선택)
- **금지**: 그린 카드 배경, 그린 박스, 그린 다이어그램, 그린 큰 영역
