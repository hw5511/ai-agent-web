# Session 1 — AI로 웹 만드는 세계 (청사진)

## 회차 개요

- **시간**: 2시간
- **트랙**: Basic / Part 1
- **1개념**: **AI 시대 웹 만들기란 무엇인가**
- **목표**: Claude Design을 직접 체험하면서 "랜딩페이지는 누구나 만들 수 있다"를 몸으로 안 다음, 16주 동안 그 너머로 갈 청사진을 받는다.
- **누적 위치**: **모든 회차의 출발점**. 학생이 본인 정체성("AI를 잘 부리는 사람")을 잡는 회차.
- **회차 끝 학생 상태**: 본인이 만든 Claude Design 페이지 1개 + 16주 후 본인 모습의 청사진 + 첫 Hello World

### 슬라이드별 topics

- **02 Claude Design 안내**: claude.ai/design 접속 / 본인 주제 1개 결정(포트폴리오·카페·취미블로그 등) / 1시간 동안 자유롭게 만들기 / 결과물 핸드오프(tar.gz) 받는 법 시연
- **03 랜딩페이지란**: 1페이지 스크롤형 / "보여주기 위한 페이지" / Wix·Webflow·Framer로도 만들 수 있는 것
- **04 4갈래**: 랜딩(이 수업) / SaaS(Notion·Slack 같은 서비스) / 쇼핑몰(자사몰·스토어) / 사내도구(내부 시스템) — 사례 사진 3개씩
- **05 청사진**: Part 1 = 랜딩 통제 + 배포까지 / Part 2 = 데이터·회원·도메인·결제까지 / "16주 후 너희는 본인 도메인의 결제 도는 사이트를 가짐"
- **06 메타 키워드**: HTML(뼈대)·CSS(스타일)·JS(행동) / React(컴포넌트 = UXUI 디자이너 현 작업방식) / DESIGN.md(Google이 만든 AI 시대 디자인 표준)
- **07 핵심 메시지**: "Claude Design이 이렇게 잘 만들어주는데 왜 더 배워?" / 답: "결과물을 진짜 내 것으로 통제하려면 코드를 알아야 함"
- **08 Hello World**: Claude Code 환경 확인 / "안녕하세요" 페이지 만들기 / 다음 주: HTML 뼈대
