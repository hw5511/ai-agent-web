### 슬라이드별 topics

- **02 도메인**: example.com 같은 사람이 읽기 좋은 주소 / IP 주소 대신 / "내 가게 간판"
- **03 시장**: 가비아(한국 친화) / Namecheap(국제) / Cloudflare(개발자 친화) / 가격 비교 (.com $10~15/년)
- **04 구매**: 가비아 가입 / 원하는 이름 검색 / 결제 / "도메인 등록 완료" 확인
- **05 DNS**: A 레코드 = IP로 / CNAME = 다른 도메인으로 / TTL 개념 가볍게
- **06 GitHub 연결**: 레포 Settings → Pages → Custom domain / 가비아 DNS에 4개 A 레코드 + CNAME
- **07 SSL**: GitHub Pages가 Let's Encrypt 자동 / "https" 체크박스 / 전파 시간 (몇 분~몇 시간)
- **08 공유**: 학생끼리 본인 도메인 자랑 / wow 모먼트
