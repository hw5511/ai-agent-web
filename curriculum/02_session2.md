# Session 2 — HTML, 웹의 뼈대

## 회차 개요

- **시간**: 2시간
- **트랙**: Basic / Part 1
- **1개념**: **구조 = HTML**
- **목표**: HTML 시맨틱 태그로 본인 랜딩페이지의 뼈대를 만든다. "구조와 디자인 분리" 지시법을 익힌다.
- **누적 위치**: 모든 회차의 베이스가 되는 첫 랜딩페이지 HTML 뼈대 완성.
- **회차 끝 학생 상태**: 본인 랜딩페이지 HTML 뼈대 (스타일 없는 검은 글씨 페이지)

### 슬라이드별 topics

- **02 HTML**: 뼈대(건물 기둥) / 브라우저가 처음 읽는 것 / 보이지 않지만 모든 화면의 기초
- **03 시맨틱 태그**: header(상단)·main(본문)·section(영역)·article(독립글)·footer(하단)
- **04 뼈대 실습**: "스타일 없이 구조만" 명시의 중요성 / 구체 항목 명시(이름·직업·소개·버튼)
- **05 분리의 이유**: 같은 뼈대 → 다양한 스타일 / 수정 시 한쪽만 건드림 / 다음 주 CSS로 옷 입힐 준비
- **06 섹션 추가**: 본인 페이지 주제에 맞게 자유 / Hero·About·Works·Contact 패턴
- **07 외부 자원**: a 태그·img 태그 / loremflickr.com/{w}/{h}/{키워드} 임시 이미지
