# Session 12 — 회원 시스템 (Supabase Auth)

## 회차 개요

- **시간**: 2시간
- **트랙**: 심화 / Part 2
- **1개념**: **사용자 인증 — 회원가입·로그인**
- **목표**: Supabase Auth로 회원가입·로그인·로그아웃을 구현하고 "내 사용자만 보는 데이터" 개념을 익힌다.
- **누적 위치**: 11주 모든 사용자 공유 DB → 12주 "내 데이터만" 분리.
- **회차 끝 학생 상태**: 회원만 글을 쓰고 볼 수 있는 페이지

### 슬라이드별 topics

- **02 왜 회원**: 익명 방명록 vs 내 일기장 / 책임·프라이버시
- **03 Supabase Auth**: 이메일·OAuth(Google·GitHub) / 가입 즉시 사용 / JWT 자동 관리
- **04 회원가입**: signUp 메서드 / 이메일 인증 옵션 / 가입 폼 UI
- **05 로그인**: signInWithPassword / onAuthStateChange로 세션 감지 / signOut 버튼
- **06 내 데이터**: 테이블에 user_id 컬럼 / RLS = "다른 사람 데이터 못 보게" / Supabase UI에서 정책 설정
- **07 내 글만**: 글 작성 시 user_id 자동 / 조회 시 .eq('user_id', currentUser.id) 또는 RLS
