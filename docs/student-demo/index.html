AI Agent Web · Part 1 (기초 8주)

프롬프트만 따라 입력하면
이렇게 쌓인다

웹을 처음 배우는 수강생이 각 회차의 실습 프롬프트를 그대로 입력했을 때 나오는 결과물을 회차별로 모았다. 2주차 한 페이지에서 시작해 매주 디자인·인터랙션·라이브러리를 누적으로 얹어, 8주차에 React 포트폴리오로 재탄생한다.

가상 수강생 이서연 · 주니어 웹 디자이너 · 카페 메뉴판·반려식물 앱·중고책 UI
팁: 4주차부터는 파티클·타이핑·3D·마우스 효과가 들어갑니다. 페이지를 열고 스크롤·마우스 이동을 해보세요. (각 회차는 그 주까지 누적된 상태입니다.)
