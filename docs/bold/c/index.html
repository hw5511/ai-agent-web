02 · 우리가 바늘을 내리는 이유

빠른 건 이미 충분합니다.
여기선 B-side로 흐릅니다

GROOVE 회현은 효율을 팔지 않습니다. 곡 사이의 정적, 판을 뒤집으러 일어서는 그 몇 초, 표지를 손끝으로 읽는 시간 · 스트리밍이 잘라낸 그 여백을 다시 돌려드리는 가게입니다.

사장이 직접 듣고 통과한 판만 매대에 오릅니다. 잡음이 심한 판엔 솔직하게 메모를 붙여둡니다. "이 판, 1분 12초에 살짝 튀어요. 그래도 연주가 좋아 들였습니다." 라고요.

  • No.1 들어보지 않은 판은 팔지 않는다
  • No.2 상태는 부풀리지 않고 적는다
  • No.3 손님이 끝까지 듣고 가게 둔다
